5. Latihan Pemecahan Masalah Larutan Penyangga (Chang Problems)

Uji pemahaman komprehensif konsep sistem penyangga (buffer) melalui studi kasus terpilih buku teks referensi General Chemistry karya Raymond Chang (Chapter 17: Acid-Base Equilibria and Solubility Equilibria, Halaman 604–609). Menelaah aksi peredaman pH terhadap gangguan asam kuat, tiga rute stoikiometri pembuatan penyangga, rasio biologis 20:1 buffer darah, dan analisis termodinamika reaksi penetralan dengan kanvas interaktif iPad.

Studi Kasus 1 · Penyangga Basa & Gangguan Asam Kuat

🧪 Problem Chang 17.72: Peredaman pH Penyangga NH3 / NH4Cl pada Penambahan HCl

Problem 17.72 · Buffer NH3/NH4Cl & HCl Tingkat: Analisis Kuantitatif Aksi Penyangga

Suatu larutan penyangga dibuat dengan mencampurkan gas amonia dan garam amonium klorida, sehingga konsentrasinya masing-masing adalah $0{,}20\text{ M } \text{NH}_3$ dan $0{,}20\text{ M } \text{NH}_4\text{Cl}$. ($K_b\text{ NH}_3 = 1{,}8 \times 10^{-5}$).
(a) Hitunglah nilai $\text{pH}$ awal dari larutan penyangga tersebut!
(b) Berapakah nilai $\text{pH}$ larutan penyangga tersebut setelah ditambahkan $10{,}0\text{ mL}$ larutan asam kuat $\text{HCl } 0{,}10\text{ M}$ ke dalam $65{,}0\text{ mL}$ larutan penyangga tersebut? (Asumsikan volume larutan bersifat aditif).
(c) Bandingkan hasil (b) seandainya $10{,}0\text{ mL } \text{HCl } 0{,}10\text{ M}$ tersebut ditambahkan ke dalam $65{,}0\text{ mL}$ air murni!

💡 Buka Kunci Jawaban & Pembahasan Peredaman pH (Problem 17.72) ↓
💡 Langkah Penyelesaian Lengkap:

(a) Menghitung pH Awal Penyangga:
$$pK_b = -\log(1{,}8 \times 10^{-5}) = 4{,}74$$ Berdasarkan persamaan Henderson-Hasselbalch untuk basa: $$\text{pOH} = pK_b + \log \frac{[\text{NH}_4^+]}{[\text{NH}_3]} = 4{,}74 + \log\left(\frac{0{,}20}{0{,}20}\right) = 4{,}74 + 0 = 4{,}74$$ $$\text{pH}_{\text{awal}} = 14{,}00 - 4{,}74 = \mathbf{9{,}26}$$

(b) Menghitung pH Setelah Ditambah $10{,}0\text{ mL HCl } 0{,}10\text{ M}$:
• Mol awal $\text{NH}_3 = 65{,}0\text{ mL} \times 0{,}20\text{ mmol/mL} = 13{,}0\text{ mmol}$
• Mol awal $\text{NH}_4^+ = 65{,}0\text{ mL} \times 0{,}20\text{ mmol/mL} = 13{,}0\text{ mmol}$
• Mol $\text{H}^+$ yang masuk $= 10{,}0\text{ mL} \times 0{,}10\text{ mmol/mL} = 1{,}0\text{ mmol}$
Reaksi penetralan penyangga: $\text{NH}_3(aq) + \text{H}^+(aq) \rightarrow \text{NH}_4^+(aq)$
• $\text{NH}_3$ sisa $= 13{,}0 - 1{,}0 = 12{,}0\text{ mmol}$
• $\text{NH}_4^+$ bertambah $= 13{,}0 + 1{,}0 = 14{,}0\text{ mmol}$
Volume total $= 65{,}0 + 10{,}0 = 75{,}0\text{ mL}$. $$\text{pOH} = 4{,}74 + \log\left(\frac{14{,}0\text{ mmol}}{12{,}0\text{ mmol}}\right) = 4{,}74 + \log(1{,}167) = 4{,}74 + 0{,}067 = 4{,}81$$ $$\text{pH}_{\text{akhir}} = 14{,}00 - 4{,}81 = \mathbf{9{,}19}$$ Nilai pH hanya turun sebesar $0{,}07$ unit (dari $9{,}26$ menjadi $9{,}19$).

(c) Perbandingan dengan Air Murni:
Jika $1{,}0\text{ mmol HCl}$ dimasukkan ke dalam $65{,}0\text{ mL}$ air murni ($\text{pH} = 7{,}0$): $$[\text{H}^+] = \frac{1{,}0\text{ mmol}}{75{,}0\text{ mL}} = 0{,}0133\text{ M} \implies \text{pH} = -\log(0{,}0133) = \mathbf{1{,}88}$$ Pada air murni, pH anjlok drastis lebih dari $5\text{ unit pH}$ (dari $7{,}0$ ke $1{,}88$). Ini membuktikan daya redam larutan penyangga yang luar biasa!

Studi Kasus 2 · Stoikiometri Laboratorium

🧪 Problem Chang 17.95: Tiga Rute Stoikiometri Pembuatan Penyangga Asetat

Problem 17.95 · Pembuatan 1 L Penyangga Asetat 0,20 M Tingkat: Perancangan Sintesis Laboratorium

Seorang laboran diminta menyiapkan $1{,}0\text{ Liter}$ larutan penyangga yang memiliki konsentrasi $0{,}20\text{ M } \text{CH}_3\text{COOH}$ dan $0{,}20\text{ M } \text{CH}_3\text{COONa}$. Di laboratorium tersedia larutan stok: $\text{CH}_3\text{COOH } 0{,}40\text{ M}$, $\text{CH}_3\text{COONa } 0{,}40\text{ M}$, $\text{NaOH } 0{,}40\text{ M}$, dan $\text{HCl } 0{,}40\text{ M}$, serta air suling.
Jelaskan secara rinci volume dan langkah pencampuran untuk membuat penyangga tersebut melalui 3 rute berbeda:
(a) Rute 1 (Pencampuran Langsung): Mencampurkan larutan $\text{CH}_3\text{COOH}$ dengan $\text{CH}_3\text{COONa}$.
(b) Rute 2 (Reaksi Asam Lemah + Basa Kuat): Mereaksikan larutan $\text{CH}_3\text{COOH}$ dengan $\text{NaOH}$.
(c) Rute 3 (Reaksi Garam Basa + Asam Kuat): Mereaksikan larutan $\text{CH}_3\text{COONa}$ dengan $\text{HCl}$.

💡 Buka Kunci Jawaban & Panduan 3 Rute Sintesis (Problem 17.95) ↓
💡 Analisis Stoikiometri 3 Rute:

Target larutan akhir ($1{,}0\text{ L}$): mengandung $0{,}20\text{ mol } \text{CH}_3\text{COOH}$ dan $0{,}20\text{ mol } \text{CH}_3\text{COONa}$.

(a) Rute 1 (Pencampuran Langsung):
• Volume $\text{CH}_3\text{COOH } 0{,}40\text{ M} = \frac{0{,}20\text{ mol}}{0{,}40\text{ M}} = 0{,}50\text{ L} = \mathbf{500\text{ mL}}$
• Volume $\text{CH}_3\text{COONa } 0{,}40\text{ M} = \frac{0{,}20\text{ mol}}{0{,}40\text{ M}} = 0{,}50\text{ L} = \mathbf{500\text{ mL}}$
Langkah: Campurkan $500\text{ mL } \text{CH}_3\text{COOH } 0{,}40\text{ M}$ dengan $500\text{ mL } \text{CH}_3\text{COONa } 0{,}40\text{ M}$. Volume akhir pas $1000\text{ mL}$.

(b) Rute 2 (Reaksi Asam Lemah Berlebih + NaOH):
Reaksi: $\text{CH}_3\text{COOH} + \text{NaOH} \rightarrow \text{CH}_3\text{COONa} + \text{H}_2\text{O}$
Agar terbentuk $0{,}20\text{ mol } \text{CH}_3\text{COONa}$, dibutuhkan $0{,}20\text{ mol NaOH}$.
Agar tersisa $0{,}20\text{ mol } \text{CH}_3\text{COOH}$, maka $\text{CH}_3\text{COOH}$ awal harus $= 0{,}20 + 0{,}20 = 0{,}40\text{ mol}$.
• Volume $\text{CH}_3\text{COOH } 0{,}40\text{ M} = \frac{0{,}40\text{ mol}}{0{,}40\text{ M}} = 1{,}00\text{ L} = \mathbf{1000\text{ mL}}$
• Volume $\text{NaOH } 0{,}40\text{ M} = \frac{0{,}20\text{ mol}}{0{,}40\text{ M}} = 0{,}50\text{ L} = \mathbf{500\text{ mL}}$
Langkah: Campurkan $1000\text{ mL } \text{CH}_3\text{COOH } 0{,}40\text{ M}$ dengan $500\text{ mL } \text{NaOH } 0{,}40\text{ M}$. Volume total menjadi $1500\text{ mL}$ (berisi $0{,}20\text{ mol}$ asam dan $0{,}20\text{ mol}$ garam). Untuk mendapatkan konsentrasi $0{,}20\text{ M}$, ambil tepat $1{,}0\text{ L}$ dari larutan tersebut (atau gunakan larutan stok asam dan basa berkonsentrasi lebih pekat).

(c) Rute 3 (Reaksi Garam Berlebih + HCl):
Reaksi: $\text{CH}_3\text{COONa} + \text{HCl} \rightarrow \text{CH}_3\text{COOH} + \text{NaCl}$
Dibutuhkan $0{,}20\text{ mol HCl}$ untuk mengubah garam menjadi $0{,}20\text{ mol } \text{CH}_3\text{COOH}$.
Garam $\text{CH}_3\text{COONa}$ mula-mula harus $= 0{,}20 + 0{,}20 = 0{,}40\text{ mol}$.
• Volume $\text{CH}_3\text{COONa } 0{,}40\text{ M} = \mathbf{1000\text{ mL}}$ dan Volume $\text{HCl } 0{,}40\text{ M} = \mathbf{500\text{ mL}}$.

Studi Kasus 3 · Biokimia Fisiologis Manusia

🩸 Problem Chang 17.107: Mengapa Rasio Buffer Bikarbonat Darah Diatur 20 : 1?

Problem 17.107 · H2CO3 / HCO3⁻ (pH Darah = 7,40) Tingkat: Analisis Integrasi Biologi & Kimia

Sistem penyangga utama dalam plasma darah manusia adalah sistem asam karbonat-bikarbonat: $$\text{CO}_2(d) + \text{H}_2\text{O}(l) \rightleftharpoons \text{H}_2\text{CO}_3(aq) \rightleftharpoons \text{H}^+(aq) + \text{HCO}_3^-(aq)$$ dengan tetapan disosiasi efektif $pK_{a1} = 6{,}10$ pada suhu tubuh $37^\circ\text{C}$.
(a) Hitunglah rasio perbandingan konsentrasi molar basa konjugasi terhadap asamnya ($\frac{[\text{HCO}_3^-]}{[\text{H}_2\text{CO}_3]}$) pada $\text{pH}$ darah normal $7{,}40$!
(b) Teori kapasitas penyangga menyatakan bahwa kapasitas buffer maksimum tercapai saat $\text{pH} = pK_a$ (rasio $1 : 1$). Mengapa tubuh manusia justru memelihara rasio yang sangat tidak seimbang ($20 : 1$)?
(c) Mengapa sistem penyangga darah disebut sebagai sistem terbuka (open buffer system) dan bagaimana hiperventilasi memicu alkalosis respiratorik?

💡 Buka Kunci Jawaban & Pembahasan Biokimia Darah (Problem 17.107) ↓
💡 Solusi & Penjelasan Fisiologis:

(a) Perhitungan Rasio Henderson-Hasselbalch:
$$\text{pH} = pK_{a1} + \log\left(\frac{[\text{HCO}_3^-]}{[\text{H}_2\text{CO}_3]}\right)$$ $$7{,}40 = 6{,}10 + \log\left(\frac{[\text{HCO}_3^-]}{[\text{H}_2\text{CO}_3]}\right)$$ $$\log\left(\frac{[\text{HCO}_3^-]}{[\text{H}_2\text{CO}_3]}\right) = 7{,}40 - 6{,}10 = 1{,}30$$ $$\frac{[\text{HCO}_3^-]}{[\text{H}_2\text{CO}_3]} = 10^{1{,}30} \approx \mathbf{19{,}95 \approx 20}$$ Rasio bikarbonat terhadap asam karbonat di dalam plasma darah adalah tepat $\mathbf{20 : 1}$.

(b) Alasan Rasio Asimetris 20 : 1:
Aktivitas metabolisme seluler manusia menghasilkan produk limbah berupa senyawa asam dalam jumlah masif (seperti asam laktat dari otot, asam piruvat, asam asetoasetat dari pemecahan lemak, dan gas $\text{CO}_2$). Sebaliknya, tubuh hampir tidak pernah menghasilkan senyawa basa.
Oleh karena itu, bahaya utama tubuh adalah ancaman asidosis (penurunan pH darah). Dengan menyediakan ion $\text{HCO}_3^-$ $20\text{ kali lebih banyak}$ dibanding asam karbonat, darah memiliki benteng pertahanan yang sangat kokoh untuk menetralkan asam hasil metabolisme.

(c) Sistem Penyangga Terbuka & Alkalosis:
Sistem ini bersifat terbuka karena konsentrasi $\text{H}_2\text{CO}_3$ dikontrol secara independen oleh pernapasan paru-paru (menghembuskan gas $\text{CO}_2$), sementara konsentrasi $\text{HCO}_3^-$ dikontrol oleh reabsorpsi ginjal.
Saat seseorang bernapas terlalu cepat dan dalam (hiperventilasi), gas $\text{CO}_2$ terbuang keluar tubuh terlalu banyak. Berdasarkan Asas Le Châtelier, kesetimbangan bergeser ke kiri ($\text{H}^+ + \text{HCO}_3^- \rightarrow \text{CO}_2 + \text{H}_2\text{O}$), menyebabkan $[\text{H}^+]$ darah anjlok dan $\text{pH}$ darah naik di atas $7{,}45$ (kondisi alkalosis respiratorik).

Studi Kasus 4 · Termodinamika Reaksi Asam-Basa

⚗️ Problem Chang 17.93: Pembuktian Mengapa Reaksi Asam-Basa Berlangsung Sempurna

Problem 17.93 · Tetapan K Penetralan (Ka, Kb, Kw) Tingkat: Analisis Kesetimbangan Termodinamika

Dalam perhitungan larutan penyangga dan titrasi, kita selalu mengasumsikan bahwa penambahan asam kuat atau basa kuat bereaksi secara sempurna ($100\%$) dengan spesi penyangganya.
Buktikan validitas asumsi tersebut dengan menghitung nilai tetapan kesetimbangan ($K$) pada $25^\circ\text{C}$ untuk 4 tipe reaksi penetralan berikut:
(a) Asam kuat dengan basa kuat: $\text{H}^+(aq) + \text{OH}^-(aq) \rightleftharpoons \text{H}_2\text{O}(l)$
(b) Asam kuat dengan basa lemah: $\text{H}^+(aq) + \text{NH}_3(aq) \rightleftharpoons \text{NH}_4^+(aq) \quad (K_b\text{ NH}_3 = 1{,}8 \times 10^{-5})$
(c) Asam lemah dengan basa kuat: $\text{CH}_3\text{COOH}(aq) + \text{OH}^-(aq) \rightleftharpoons \text{CH}_3\text{COO}^-(aq) + \text{H}_2\text{O}(l) \quad (K_a = 1{,}8 \times 10^{-5})$
(d) Asam lemah dengan basa lemah: $\text{CH}_3\text{COOH}(aq) + \text{NH}_3(aq) \rightleftharpoons \text{CH}_3\text{COO}^-(aq) + \text{NH}_4^+(aq)$

💡 Buka Kunci Jawaban & Hitungan Tetapan K (Problem 17.93) ↓
💡 Perhitungan Tetapan Kesetimbangan:

(a) Asam Kuat + Basa Kuat:
Reaksi ini adalah kebalikan dari autoionisasi air ($\text{H}_2\text{O} \rightleftharpoons \text{H}^+ + \text{OH}^-$): $$K = \frac{1}{K_w} = \frac{1}{1{,}0 \times 10^{-14}} = \mathbf{1{,}0 \times 10^{14}}$$ Nilai $K = 10^{14}$ adalah angka yang luar biasa raksasa, membuktikan reaksi penetralan berlangsung $100\%$ tuntas ke kanan.

(b) Asam Kuat + Basa Lemah ($\text{NH}_3$):
Reaksi: $\text{H}^+ + \text{NH}_3 \rightleftharpoons \text{NH}_4^+$. Hubungan dengan $K_b$: $$K = \frac{[\text{NH}_4^+]}{[\text{H}^+][\text{NH}_3]} \times \frac{[\text{OH}^-]}{[\text{OH}^-]} = \frac{K_b}{K_w} = \frac{1{,}8 \times 10^{-5}}{1{,}0 \times 10^{-14}} = \mathbf{1{,}8 \times 10^9}$$ Nilai $K \approx 1{,}8\text{ miliar}$ menunjukkan reaksi praktis tuntas sempurna.

(c) Asam Lemah ($\text{CH}_3\text{COOH}$) + Basa Kuat:
Reaksi: $\text{CH}_3\text{COOH} + \text{OH}^- \rightleftharpoons \text{CH}_3\text{COO}^- + \text{H}_2\text{O}$. $$K = \frac{[\text{CH}_3\text{COO}^-]}{[\text{CH}_3\text{COOH}][\text{OH}^-]} \times \frac{[\text{H}^+]}{[\text{H}^+]} = \frac{K_a}{K_w} = \frac{1{,}8 \times 10^{-5}}{1{,}0 \times 10^{-14}} = \mathbf{1{,}8 \times 10^9}$$

(d) Asam Lemah + Basa Lemah:
$$K = \frac{[\text{CH}_3\text{COO}^-][\text{NH}_4^+]}{[\text{CH}_3\text{COOH}][\text{NH}_3]} = \frac{K_a \cdot K_b}{K_w} = \frac{(1{,}8 \times 10^{-5})(1{,}8 \times 10^{-5})}{1{,}0 \times 10^{-14}} = \mathbf{3{,}2 \times 10^4}$$ Bahkan untuk asam lemah dan basa lemah, nilai $K = 32.400$ tetap jauh lebih besar dari 1 ($K \gg 1$), membuktikan semua penetralan asam-basa condong sangat kuat ke arah produk!
