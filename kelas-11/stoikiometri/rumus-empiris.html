3. Rumus Empiris & Molekul

Konsep Dasar Langkah Penentuan Analisis Pembakaran Ke Rumus Molekul Latihan

💡 Apa Bedanya Rumus Empiris dan Rumus Molekul?

Rumus empiris hanya menyatakan perbandingan jumlah atom paling sederhana antar unsur penyusun senyawa. Rumus molekul menyatakan jumlah atom yang sesungguhnya menyusun satu molekul senyawa itu. Contohnya, glukosa:

🔡

Rumus Empiris

CH2O

rasio atom paling sederhana (1 : 2 : 1)

🧬

Rumus Molekul

C6H12O6

jumlah atom sesungguhnya (glukosa)

Hubungan Keduanya

Rumus Molekul = (Rumus Empiris) × n

Mr Molekul = Mr Empiris × n

Keterangan: n adalah bilangan bulat (1, 2, 3, ...) yang menyatakan berapa kali rumus empiris "digandakan".

Karena rumus empiris hanyalah rasio, dua senyawa yang sifatnya sangat berbeda bisa memiliki rumus empiris yang identik:

Senyawa Rumus Molekul Rumus Empiris n
AirH2OH2O1
Hidrogen peroksidaH2O2HO2
EtanaC2H6CH32
BenzenaC6H6CH6
Asam asetat (cuka)C2H4O2CH2O2
GlukosaC6H12O6CH2O6

Perhatikan: asam asetat dan glukosa punya rumus empiris yang sama persis, padahal senyawanya jauh berbeda. Rumus empiris saja belum cukup untuk mengenali suatu senyawa.

2. Menentukan Rumus Empiris dari Persen Komposisi

Hasil analisis laboratorium biasanya berupa persentase massa tiap unsur. Berikut alur bakunya:

Langkah 1

Anggap sampel bermassa tepat 100 gram, sehingga setiap persen (%) langsung berarti jumlah gram unsur tersebut.

Langkah 2

Ubah massa (gram) tiap unsur menjadi mol dengan membaginya dengan Ar unsur tersebut.

Langkah 3

Bagi jumlah mol tiap unsur dengan jumlah mol terkecil di antara semuanya.

Langkah 4

Jika hasilnya belum bilangan bulat, kalikan semua rasio dengan bilangan bulat terkecil yang membuat semuanya utuh.

Langkah 5

Tuliskan rumus empirisnya menggunakan bilangan bulat itu sebagai subskrip.

📌 Tabel Pengali Cepat (Langkah 4)

…,20 → ×5
…,25 → ×4
…,33 → ×3
…,50 → ×2

✏️ Contoh Soal: Rumus Empiris dari Persen Komposisi

Suatu senyawa organik mengandung 40,0% karbon, 6,7% hidrogen, dan 53,3% oksigen menurut massa. Tentukan rumus empirisnya.
(Diketahui Ar C = 12, H = 1, O = 16)

Langkah Penyelesaian:

1. Anggap sampel 100 gram → C = 40,0 g; H = 6,7 g; O = 53,3 g.

2. Ubah ke mol:

nC =
40,0 gram 12 gram/mol
= 3,33 mol
nH =
6,7 gram 1 gram/mol
= 6,70 mol
nO =
53,3 gram 16 gram/mol
= 3,33 mol

3. Bagi dengan mol terkecil (3,33):
C : H : O = 1,00 : 2,01 : 1,00 ≈ 1 : 2 : 1

Rumus Empiris = CH2O
Catatan: senyawa dengan komposisi ini bisa jadi formaldehida (CH2O), asam asetat (C2H4O2), atau glukosa (C6H12O6). Lanjut ke bagian 4 untuk melihat cara memastikannya lewat Mr.

3. Penentuan dari Data Eksperimen: Analisis Pembakaran

Untuk senyawa organik (C, H, dan kadang O), persen komposisi jarang diberikan langsung. Sampel dibakar sempurna dalam kelebihan oksigen: semua atom karbon berakhir sebagai gas CO2, semua atom hidrogen berakhir sebagai uap H2O. Kedua gas ini ditangkap terpisah lalu ditimbang.

  • Massa karbon dihitung mundur dari massa CO2 yang terbentuk.
  • Massa hidrogen dihitung mundur dari massa H2O yang terbentuk.
  • Jika senyawa mengandung oksigen, massanya didapat dari selisih: massa sampel dikurangi massa C dan H, karena oksigen dari udara pembakaran ikut campur pada gas hasil.

✏️ Contoh Soal: Rumus Empiris dari Data Pembakaran

Pembakaran sempurna 4,60 gram senyawa organik (C, H, O) menghasilkan 8,80 gram CO2 dan 5,40 gram H2O. Tentukan rumus empirisnya.
(Diketahui Ar C = 12, H = 1, O = 16; Mr CO2 = 44, Mr H2O = 18)

Langkah Penyelesaian:

1. Massa C dari CO2:

nCO2 =
8,80 gram 44 gram/mol
= 0,200 mol = nC
massa C = 0,200 mol × 12 gram/mol = 2,40 gram

2. Massa H dari H2O:

nH2O =
5,40 gram 18 gram/mol
= 0,300 mol → nH = 2 × 0,300 = 0,600 mol
massa H = 0,600 mol × 1 gram/mol = 0,600 gram

3. Massa O = massa sampel − (massa C + massa H):
4,60 − (2,40 + 0,600) = 1,60 gram O → nO = 1,60 ÷ 16 = 0,100 mol

4. Bagi dengan mol terkecil (0,100):
C : H : O = 2,00 : 6,00 : 1,00

Rumus Empiris = C2H6O

4. Dari Rumus Empiris ke Rumus Molekul

Rumus molekul selalu kelipatan bulat dari rumus empiris. Jika Mr senyawa sesungguhnya sudah diketahui (biasanya dari spektrometri massa), bilangan pengali n dicari dengan:

n =
Mr Molekul
Mr Empiris

✏️ Contoh Soal: Melanjutkan Data Pembakaran

Senyawa dengan rumus empiris C2H6O (dari contoh sebelumnya) diketahui memiliki Mr ≈ 46 g/mol. Tentukan rumus molekulnya.

1. Mr rumus empiris:
Mr (C2H6O) = 2(12) + 6(1) + 16 = 46 gram/mol

2. n =
46 46
= 1
Rumus Molekul = C2H6O (etanol)

✏️ Contoh Soal Cepat

Rumus empiris suatu senyawa adalah CH2, dengan Mr ≈ 56 g/mol. Tentukan rumus molekulnya.

1. Mr empiris = 12 + 2(1) = 14 gram/mol

2. n =
56 14
= 4
Rumus Molekul = C4H8
