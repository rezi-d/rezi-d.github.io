Poin 1 · Konveksitas & Turunan Kedua

Fungsi Konveks ($f''(x) \ge 0$), Konkaf ($f''(x) \le 0$) & Ketaksamaan Jensen

Senjata Utama Aljabar OSN

Banyak ketaksamaan olimpiade yang tampak mustahil diselesaikan dengan AM-GM atau Cauchy-Schwarz dapat ditaklukkan dalam tiga baris menggunakan Ketaksamaan Jensen! Secara geometris, pada fungsi konveks (cekung ke atas, $f''(x) \ge 0$), titik tengah tali busur selalu berada di atas titik pada kurva:

Interpretasi Geometris Ketaksamaan Jensen pada Fungsi Konveks ($f''(x) \ge 0$): Rata-Rata Fungsi $\ge$ Fungsi Rata-Rata

1. Fungsi Konveks ($f''(x) \ge 0$ pada $I$)

$$\frac{f(x_1) + f(x_2) + \dots + f(x_n)}{n} \ge f\left(\frac{x_1 + x_2 + \dots + x_n}{n}\right)$$

Contoh: $x^2, x^n (n \ge 1, x > 0), e^x, -\ln x, \tan x$ pada $(0, \pi/2)$.

2. Fungsi Konkaf ($f''(x) \le 0$ pada $I$)

$$\frac{f(x_1) + f(x_2) + \dots + f(x_n)}{n} \le f\left(\frac{x_1 + x_2 + \dots + x_n}{n}\right)$$

Contoh: $\sqrt{x}, \ln x, \sin x$ pada $(0, \pi)$. Kesamaan terjadi jika dan hanya jika $x_1 = x_2 = \dots = x_n$.

Poin 2 · Ketaksamaan Sudut Segitiga

Nilai Ekstremum Trigonometri Segitiga dengan Jensen

$A + B + C = 180^\circ$

Pada setiap segitiga $\triangle ABC$, jumlah ketiga sudutnya konstan $A + B + C = \pi$ ($180^\circ$), sehingga rata-rata ketiga sudutnya selalu $\frac{A + B + C}{3} = \frac{\pi}{3} = 60^\circ$.

Pembuktian 3 Baris: $\sin A + \sin B + \sin C \le \frac{3\sqrt{3}}{2}$

Tinjau fungsi $f(x) = \sin x$ pada interval sudut segitiga $x \in (0, \pi)$. Turunan keduanya adalah $f''(x) = -\sin x < 0$, sehingga $f(x) = \sin x$ adalah fungsi konkaf pada $(0, \pi)$. Dengan Ketaksamaan Jensen:

$$\frac{\sin A + \sin B + \sin C}{3} \le \sin\left(\frac{A + B + C}{3}\right) = \sin(60^\circ) = \frac{1}{2}\sqrt{3} \implies \sin A + \sin B + \sin C \le \frac{3}{2}\sqrt{3}$$

Nilai maksimum $\frac{3}{2}\sqrt{3}$ tercapai saat segitiga tersebut sama sisi ($A = B = C = 60^\circ$).

Poin 3 · Eksistensi Titik & Akar Turunan

Teorema Rolle & Teorema Nilai Rata-Rata (MVT) Lagrange

Gradien Sekan = Singgung

Teorema Nilai Rata-Rata Lagrange: Ada $c \in (a, b)$ di mana Garis Singgung Sejajar Tali Busur $AB$

1. Teorema Rolle

Jika $f$ kontinu pada $[a,b]$, terdiferensialkan pada $(a,b)$, dan $f(a) = f(b)$, maka terdapat $c \in (a,b)$ sehingga $f'(c) = 0$. (Di antara dua akar $f(x)$ selalu ada minimal satu akar $f'(x)$!).

2. Aplikasi Ketaksamaan Lipschitz

Karena $\frac{\sin b - \sin a}{b - a} = \cos c$ dan $|\cos c| \le 1$, maka untuk setiap $a, b \in \mathbb{R}$ berlaku $|\sin b - \sin a| \le |b - a|$.

Poin 4 · Tangent Line Trick

Trik Garis Singgung untuk Membuktikan Ketaksamaan Simetris

$f(x) \ge f(x_0) + f'(x_0)(x - x_0)$

Sifat ajaib fungsi konveks adalah grafiknya selalu berada di atas garis singgungnya! Jika kita ingin membuktikan $\sum f(x_i) \ge 3f(x_0)$ dengan syarat $x_1 + x_2 + x_3 = 3x_0$, cukup cari persamaan garis singgung $y = f(x_0) + f'(x_0)(x - x_0)$ di titik kesamaan $x = x_0$:

Rumus Umum Tangent Line Trick (Untuk $f$ Konveks di Sekitar $x_0$):

$$f(x) \ge f(x_0) + f'(x_0)(x - x_0)$$

Saat dijumlahkan untuk $x = a, b, c$, suku $f'(x_0)\big[(a - x_0) + (b - x_0) + (c - x_0)\big]$ akan saling menghilangkan menjadi $0$ karena $a + b + c = 3x_0$!
