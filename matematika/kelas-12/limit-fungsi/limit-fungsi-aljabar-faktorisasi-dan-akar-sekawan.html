2. Limit Fungsi Aljabar: Faktorisasi & Rasionalisasi Akar

Ketika substitusi langsung menghasilkan bentuk tak tentu $\frac{0}{0}$, artinya baik pembilang maupun penyebut sama-sama menyimpan faktor pembuat nol $(x - c)$. Kuasai tiga teknik aljabar untuk memunculkan dan mencoret faktor $(x - c)$: pemfaktoran polinomial (termasuk skema Horner), perkalian akar sekawan, serta substitusi pemisalan akar pangkat-$n$.

Poin 1 / 5
Poin 1 · Diagnosis Awal Limit

🔍 Diagnosis Substitusi: Bentuk Tentu vs Bentuk Tak Tentu $\frac{0}{0}$

Visualisasi Limit Bentuk Tak Tentu 0/0 sebagai Titik Berlubang (a, L)
Faktor (x - c)

Langkah pertama dalam mengerjakan soal limit wajib selalu substitusi langsung $x = c$ ke dalam $\frac{f(x)}{g(x)}$. Terdapat tiga kemungkinan hasil:

1. Hasil $\frac{k}{m}$ ($m \ne 0$)
Bentuk Tentu (Selesai!)

Termasuk $\frac{0}{5} = 0$. Itu sudah merupakan nilai akhir limit, tidak perlu difaktorkan lagi!

2. Hasil $\frac{k}{0}$ ($k \ne 0$)
Asimtot Tegak ($\pm\infty$ / DNE)

Nilai fungsi meledak menuju $+\infty$ atau $-\infty$. Limit bernilai tak hingga (tidak memiliki limit hingga).

3. Hasil $\frac{0}{0}$
Bentuk Tak Tentu!

Berdasarkan Teorema Faktor, karena $f(c) = 0$ dan $g(c) = 0$, keduanya pasti habis dibagi $(x - c)$!

🎯 Misi Utama pada Bentuk $\frac{0}{0}$:

Ubah bentuk fungsi agar faktor pembuat nol $(x - c)$ muncul eksplisit di pembilang dan penyebut, lalu coret $(x - c)$ (sah dicoret karena $x \to c$ berarti $x \ne c \implies x - c \ne 0$): $$\lim_{x \to c} \frac{(x - c) \cdot P(x)}{(x - c) \cdot Q(x)} = \lim_{x \to c} \frac{P(x)}{Q(x)} = \frac{P(c)}{Q(c)}$$

Poin 2 · Faktorisasi Polinomial

🧱 Metode Pemfaktoran Aljabar & Skema Horner Derajat Tinggi

Visualisasi Limit Bentuk Tak Tentu 0/0 sebagai Titik Berlubang (a, L)
a³ ± b³ & Horner

Identitas Pemfaktoran Wajib Hafal:

1. $a^2 - b^2 = (a - b)(a + b)$
2. $a^3 - b^3 = (a - b)(a^2 + ab + b^2)$
3. $a^3 + b^3 = (a + b)(a^2 - ab + b^2)$
4. $a^n - b^n = (a - b)(a^{n-1} + a^{n-2}b + \dots + b^{n-1})$
Contoh 1: Selisih Pangkat Tiga

Hitunglah $\lim_{x \to 2} \frac{x^3 - 8}{x^2 - x - 2}$:
• Substitusi $x=2$ menghasilkan $\frac{8-8}{4-2-2} = \frac{0}{0}$.
• Faktorkan $(x - 2)$ dari pembilang dan penyebut: $$\lim_{x \to 2} \frac{(x - 2)(x^2 + 2x + 4)}{(x - 2)(x + 1)}$$ $$= \lim_{x \to 2} \frac{x^2 + 2x + 4}{x + 1} = \frac{2^2 + 2(2) + 4}{2 + 1} = \frac{12}{3} = \mathbf{4}$$

Contoh 2: Polinomial Derajat Tinggi via Horner

Hitunglah $\lim_{x \to 1} \frac{x^3 - 4x^2 + 5x - 2}{x^2 - 1}$:
• Bagi $x^3 - 4x^2 + 5x - 2$ dengan $(x - 1)$ menggunakan skema Horner ($c = 1$ pada koefisien $1, -4, 5, -2$), diperoleh hasil bagi $x^2 - 3x + 2$: $$\lim_{x \to 1} \frac{(x - 1)(x^2 - 3x + 2)}{(x - 1)(x + 1)} = \frac{1^2 - 3(1) + 2}{1 + 1} = \frac{0}{2} = \mathbf{0}$$

Poin 3 · Limit Bentuk Irasional (Akar)

✨ Metode Perkalian Akar Sekawan (Rationalization)

Visualisasi Limit Bentuk Tak Tentu 0/0 sebagai Titik Berlubang (a, L)
(√A - √B)(√A + √B) = A - B

Jika bentuk tak tentu $\frac{0}{0}$ memuat bentuk akar kuadrat $\sqrt{u} - \sqrt{v}$, kalikan pembilang dan penyebut dengan bentuk sekawannya yaitu $\frac{\sqrt{u} + \sqrt{v}}{\sqrt{u} + \sqrt{v}}$ agar tanda akarnya hilang menjadi $u - v$.

💡 Trik Hitung Cepat Sekawan ($\sqrt{u} + \sqrt{v} \to 2\sqrt{u}$):

Karena saat $x = c$ nilai $\sqrt{u(c)}$ dan $\sqrt{v(c)}$ pasti sama besar (sebab selisihnya nol!), Anda tidak perlu menulis panjang-panjang faktor sekawan $(\sqrt{u} + \sqrt{v})$ di setiap langkah — nilai faktor sekawan tersebut saat disubstitusi $x = c$ selalu bernilai **$2\sqrt{u(c)}$**!

Studi Kasus: $\lim_{x \to 3} \frac{\sqrt{2x + 3} - 3}{x - 3}$

1. Substitusi $x = 3$: $\frac{\sqrt{9} - 3}{3 - 3} = \frac{0}{0}$.
2. Kalikan dengan sekawan $\frac{\sqrt{2x + 3} + 3}{\sqrt{2x + 3} + 3}$: $$\lim_{x \to 3} \frac{(\sqrt{2x + 3} - 3)(\sqrt{2x + 3} + 3)}{(x - 3)(\sqrt{2x + 3} + 3)} = \lim_{x \to 3} \frac{(2x + 3) - 9}{(x - 3)(\sqrt{2x + 3} + 3)}$$ $$= \lim_{x \to 3} \frac{2(x - 3)}{(x - 3)(\sqrt{2x + 3} + 3)} = \frac{2}{\sqrt{2(3) + 3} + 3} = \frac{2}{3 + 3} = \mathbf{\frac{1}{3}}$$

Poin 4 · Akar Pangkat Tiga & Campuran

🚀 Teknik Pemisalan Variabel ($u = \sqrt[n]{x}$) untuk Akar Pangkat Tinggi

Visualisasi Limit Bentuk Tak Tentu 0/0 sebagai Titik Berlubang (a, L)
Substitusi u = x^(1/n)

Bagaimana jika soal limit memuat akar pangkat tiga ($\sqrt[3]{x}$) atau gabungan $\sqrt{x}$ dan $\sqrt[3]{x}$? Mengalikan sekawan pangkat tiga sering kali memakan waktu. Cara paling elegan adalah mengganti variabel dengan KPK dari pangkat akarnya!

Contoh 1: $\lim_{x \to 8} \frac{\sqrt[3]{x} - 2}{x - 8}$

• Misalkan **$u = \sqrt[3]{x} \implies x = u^3$**.
• Saat $x \to 8$, maka $u \to \sqrt[3]{8} = 2$.
• Soal langsung berubah menjadi polinomial biasa: $$\lim_{u \to 2} \frac{u - 2}{u^3 - 8} = \lim_{u \to 2} \frac{u - 2}{(u - 2)(u^2 + 2u + 4)}$$ $$= \frac{1}{2^2 + 2(2) + 4} = \mathbf{\frac{1}{12}}$$

Contoh 2: $\lim_{x \to 64} \frac{\sqrt{x} - 8}{\sqrt[3]{x} - 4}$

• KPK dari pangkat akar $2$ dan $3$ adalah $6$. Misalkan **$u = \sqrt[6]{x} \implies x = u^6$**.
• Maka $\sqrt{x} = u^3$, $\sqrt[3]{x} = u^2$, dan saat $x \to 64 \implies u \to 2$: $$\lim_{u \to 2} \frac{u^3 - 8}{u^2 - 4} = \lim_{u \to 2} \frac{(u - 2)(u^2 + 2u + 4)}{(u - 2)(u + 2)}$$ $$= \frac{2^2 + 2(2) + 4}{2 + 2} = \frac{12}{4} = \mathbf{3}$$
