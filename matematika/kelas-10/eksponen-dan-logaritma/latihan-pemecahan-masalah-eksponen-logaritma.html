1 3 Trik Aljabar Khusus Soal Kompetisi & HOTS

Strategi 1: Substitusi Simetris $u + \frac{1}{u}$

Bentuk $a^x + a^{-x}$ dapat disederhanakan dengan mengkuadratkannya:

$$(a^x + a^{-x})^2 = (a^x)^2 + 2(a^x)(a^{-x}) + (a^{-x})^2 = a^{2x} + 2 + a^{-2x}$$ $$a^{2x} + a^{-2x} = (a^x + a^{-x})^2 - 2$$
Strategi 2: Menyamakan Pangkat untuk Membandingkan Nilai Besar

Untuk membandingkan bilangan berpangkat raksasa tanpa kalkulator (seperti $2^{60}, 3^{40}, 5^{20}$), carilah FPB dari eksponennya: $\text{FPB}(60, 40, 20) = 20$.

$$2^{60} = (2^3)^{20} = 8^{20}$$ $$3^{40} = (3^2)^{20} = 9^{20}$$ $$5^{20} = (5^1)^{20} = 5^{20}$$ $$\text{Karena } 9 > 8 > 5, \text{ maka } 3^{40} > 2^{60} > 5^{20}!$$
Strategi 3: Sifat Saling Menghilangkan (Telescoping Logarithms)

Penjumlahan berantai $\log\left(1 + \frac{1}{n}\right) = \log\left(\frac{n+1}{n}\right) = \log(n+1) - \log n$ akan saling meniadakan suku-suku tengahnya secara beruntun ketika dijumlahkan!
