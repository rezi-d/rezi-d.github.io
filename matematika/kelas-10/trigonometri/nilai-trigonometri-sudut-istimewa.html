2. Nilai Perbandingan Sudut Istimewa

Kuasai nilai eksak perbandingan trigonometri pada sudut-sudut istimewa ($0^\circ, 30^\circ, 45^\circ, 60^\circ, 90^\circ$): pembuktian aljabar segitiga sama kaki dan sama sisi, pendekatan lingkaran satuan, tabel master, hingga trik mudah jari tangan.

Poin 1 · Geometri Segitiga Sama Kaki

📐 1. Penurunan Nilai Sudut $45^\circ$ ($\frac{\pi}{4}\text{ rad}$)

Sudut 45°

Segitiga Siku-Siku Sama Kaki (Sudut $45^\circ - 45^\circ - 90^\circ$)

Misalkan sebuah segitiga siku-siku memiliki dua sisi siku-siku yang sama panjang berukuran $1$ satuan ($x = 1, y = 1$):

$$r = \sqrt{1^2 + 1^2} = \sqrt{2}$$

Karena kedua sisi tegak sama panjang, kedua sudut lancipnya sama besar, yaitu $(180^\circ - 90^\circ) / 2 = 45^\circ$.

Sinus $45^\circ$
$$\sin 45^\circ = \frac{1}{\sqrt{2}} = \frac{1}{2}\sqrt{2}$$
Kosinus $45^\circ$
$$\cos 45^\circ = \frac{1}{\sqrt{2}} = \frac{1}{2}\sqrt{2}$$
Tangen $45^\circ$
$$\tan 45^\circ = \frac{1}{1} = 1$$
Karakteristik Unik: Pada sudut $45^\circ$, nilai sinus dan kosinus bernilai sama persis ($\sin 45^\circ = \cos 45^\circ = \frac{1}{2}\sqrt{2}$), dan nilai tangen tepat bernilai $1$.
Poin 2 · Geometri Segitiga Sama Sisi

🔺 2. Penurunan Nilai Sudut $30^\circ$ dan $60^\circ$

Sudut 30° & 60°

Membelah Segitiga Sama Sisi Panjang Sisi 2 Satuan

Ambil segitiga sama sisi dengan panjang sisi masing-masing $2$ satuan (ketiga sudutnya $60^\circ$). Buat garis tinggi dari puncak ke alas:

  • Alas terbagi dua sama panjang: $\frac{2}{2} = 1$ satuan.
  • Panjang garis tinggi ($t$) dihitung melalui Pythagoras: $$t = \sqrt{2^2 - 1^2} = \sqrt{4 - 1} = \sqrt{3}$$
  • Sudut puncak $60^\circ$ terbagi dua menjadi sudut $30^\circ$.
Sudut $30^\circ$ (Depan $= 1$, Samping $= \sqrt{3}$, Miring $= 2$)

$$\sin 30^\circ = \frac{1}{2}$$

$$\cos 30^\circ = \frac{\sqrt{3}}{2} = \frac{1}{2}\sqrt{3}$$

$$\tan 30^\circ = \frac{1}{\sqrt{3}} = \frac{1}{3}\sqrt{3}$$

Sudut $60^\circ$ (Depan $= \sqrt{3}$, Samping $= 1$, Miring $= 2$)

$$\sin 60^\circ = \frac{\sqrt{3}}{2} = \frac{1}{2}\sqrt{3}$$

$$\cos 60^\circ = \frac{1}{2}$$

$$\tan 60^\circ = \frac{\sqrt{3}}{1} = \sqrt{3}$$

Sifat Sudut Berpenyiku (Komplementer): Perhatikan bahwa $\sin 30^\circ = \cos 60^\circ = \frac{1}{2}$ dan $\cos 30^\circ = \sin 60^\circ = \frac{1}{2}\sqrt{3}$, karena $30^\circ + 60^\circ = 90^\circ$.
Poin 3 · Sudut Batas Kuadran

⭕ 3. Sudut Batas Kuadran $0^\circ$ dan $90^\circ$

Sudut 0° & 90°

Pendekatan Lingkaran Satuan ($r = 1$)

Pada lingkaran berpusat $(0,0)$ berjari-jari $r = 1$, setiap titik pada keliling lingkaran memiliki koordinat:

$$(x, y) = (\cos \theta, \sin \theta)$$
Sudut $\theta = 0^\circ$ (Sumbu $X$ Positif)

Titik terminal berada pada koordinat $(1, 0)$:

$$\sin 0^\circ = y = 0$$

$$\cos 0^\circ = x = 1$$

$$\tan 0^\circ = \frac{y}{x} = \frac{0}{1} = 0$$

Sudut $\theta = 90^\circ$ (Sumbu $Y$ Positif)

Titik terminal berada pada koordinat $(0, 1)$:

$$\sin 90^\circ = y = 1$$

$$\cos 90^\circ = x = 0$$

$$\tan 90^\circ = \frac{1}{0} = \text{Tidak Terdefinisi}$$
