Ketaksamaan Rataan Aritmetika - Geometri (AM-GM Inequality)

Ketaksamaan AM-GM menyatakan bahwa rata-rata hitung (aritmetika) dari sekumpulan bilangan real non-negatif selalu bernilai lebih besar atau sama dengan rata-rata ukur (geometri)-nya.

Teorema AM-GM Umum ($n$ Variabel):

Untuk setiap bilangan real non-negatif $x_1, x_2, \dots, x_n \ge 0$:

$$\frac{x_1 + x_2 + \dots + x_n}{n} \ge \sqrt[n]{x_1 x_2 \cdots x_n}$$

Syarat Kesamaan: Kesamaan ($\frac{\sum x_i}{n} = \sqrt[n]{\prod x_i}$) terjadi jika dan hanya jika $x_1 = x_2 = \dots = x_n$.

Kasus 2 Variabel ($n=2$)

Untuk $a, b \ge 0$: $\frac{a+b}{2} \ge \sqrt{ab} \iff a+b \ge 2\sqrt{ab}$.
Bukti Runtun: $(\sqrt{a}-\sqrt{b})^2 \ge 0 \iff a - 2\sqrt{ab} + b \ge 0 \iff a+b \ge 2\sqrt{ab}$.

Aplikasi: $x + \frac{1}{x} \ge 2$ untuk $x > 0$.
Kasus 3 Variabel ($n=3$)

Untuk $a, b, c \ge 0$: $\frac{a+b+c}{3} \ge \sqrt[3]{abc} \iff a+b+c \ge 3\sqrt[3]{abc}$.
Sangat ampuh meminimalkan fungsi jika perkalian antar-suku konstan.

Kesamaan berlaku saat $a = b = c$.
💡 Trik Olimpiade: Pemecahan Suku untuk Menghilangkan Variabel

Misalkan kita diminta mencari nilai minimum dari $f(x) = x + \frac{16}{x^2}$ untuk $x > 0$.
Jika langsung memakai AM-GM dua suku: $x + \frac{16}{x^2} \ge 2\sqrt{x \cdot \frac{16}{x^2}} = 2\sqrt{\frac{16}{x}}$ (masih bergantung pada variabel $x$!).
Trik: Pecah suku $x$ menjadi dua bagian sama besar: $$f(x) = \frac{x}{2} + \frac{x}{2} + \frac{16}{x^2} \ge 3 \sqrt[3]{\frac{x}{2} \cdot \frac{x}{2} \cdot \frac{16}{x^2}} = 3 \sqrt[3]{\frac{16}{4}} = 3 \sqrt[3]{4}$$ Kesamaan tercapai saat $\frac{x}{2} = \frac{16}{x^2} \implies x^3 = 32 \implies x = 2\sqrt[3]{4}$.

Ketaksamaan Cauchy-Schwarz & Bentuk Engel (Titu's Lemma)

Ketaksamaan Cauchy-Schwarz adalah pilar analisis matematika yang menghubungkan kuadrat panjang vektor dengan perkalian titik (*dot product*).

Teorema Cauchy-Schwarz:

Untuk setiap bilangan real $a_1, a_2, \dots, a_n$ dan $b_1, b_2, \dots, b_n$:

$$(a_1^2 + a_2^2 + \dots + a_n^2)(b_1^2 + b_2^2 + \dots + b_n^2) \ge (a_1 b_1 + a_2 b_2 + \dots + a_n b_n)^2$$

Syarat Kesamaan: Berlaku jika dan hanya jika terdapat konstanta $k$ sehingga $a_i = k b_i$ untuk semua $i$ (kedua barisan proposional: $\frac{a_1}{b_1} = \frac{a_2}{b_2} = \dots = \frac{a_n}{b_n}$).

Bentuk Engel / Titu's Lemma (Alat Rahasia Pecahan Olimpiade):

Substitusikan $a_i = \frac{u_i}{\sqrt{v_i}}$ dan $b_i = \sqrt{v_i}$ ke Cauchy-Schwarz dengan $v_i > 0$:

$$\frac{u_1^2}{v_1} + \frac{u_2^2}{v_2} + \dots + \frac{u_n^2}{v_n} \ge \frac{(u_1 + u_2 + \dots + u_n)^2}{v_1 + v_2 + \dots + v_n}$$

Sangat sakti untuk membuktikan ketaksamaan pecahan berpenyebut linier tanpa perlu menyamakan penyebut!

Contoh Soal Pembuktian OSN:

Diberikan $a, b, c > 0$ dengan $a + b + c = 1$. Buktikan bahwa $\frac{1}{a} + \frac{1}{b} + \frac{1}{c} \ge 9$.

Solusi Instan dengan Titu's Lemma:

$$\frac{1^2}{a} + \frac{1^2}{b} + \frac{1^2}{c} \ge \frac{(1 + 1 + 1)^2}{a + b + c} = \frac{3^2}{1} = 9$$

Kesamaan tercapai saat $\frac{1}{a} = \frac{1}{b} = \frac{1}{c} \implies a = b = c = \frac{1}{3}$. Terbukti secara elegan!

Polinomial Tingkat Tinggi & Teorema Vieta Lanjutan

Dalam soal OSN, polinomial derajat 3 atau 4 sering diuji bukan untuk dicari akarnya secara eksplisit, melainkan untuk mengeksploitasi jumlahan simetris akar-akarnya melalui Teorema Vieta.

Teorema Vieta untuk Kubik $ax^3 + bx^2 + cx + d = 0$ (Akar: $x_1, x_2, x_3$):
Jumlahan Tunggal ($e_1$) $$x_1 + x_2 + x_3 = -\frac{b}{a}$$
Jumlahan Pasangan ($e_2$) $$x_1 x_2 + x_2 x_3 + x_3 x_1 = \frac{c}{a}$$
Hasil Kali Tiga Akar ($e_3$) $$x_1 x_2 x_3 = -\frac{d}{a}$$
Konstruksi Bentuk Simetris Kuadrat dan Kubik:
  • Jumlahan Kuadrat: $x_1^2 + x_2^2 + x_3^2 = (x_1+x_2+x_3)^2 - 2(x_1 x_2 + x_2 x_3 + x_3 x_1) = e_1^2 - 2e_2$.
  • Jumlahan Kubik: Karena setiap $x_i$ memenuhi persamaan $a x_i^3 + b x_i^2 + c x_i + d = 0$, jumlahkan untuk $i=1,2,3$: $$a(x_1^3+x_2^3+x_3^3) + b(x_1^2+x_2^2+x_3^2) + c(x_1+x_2+x_3) + 3d = 0$$ Rumus rekursif ini disebut Newton's Sums, sangat menghemat waktu pengerjaan!

Manipulasi Faktorisasi Simetris Non-Rutin

Peserta olimpiade wajib mengenali identitas aljabar tingkat tinggi yang sering tersembunyi dalam persamaan non-linier.

1. Identitas Euler Kubik
$$a^3 + b^3 + c^3 - 3abc = (a+b+c)(a^2+b^2+c^2 - ab - bc - ca)$$ $$= \frac{1}{2}(a+b+c)[(a-b)^2 + (b-c)^2 + (c-a)^2]$$
✨ Sifat Emas: Jika $a+b+c = 0$, maka $a^3 + b^3 + c^3 = 3abc$. Sebaliknya, jika $a, b, c > 0$ dan $a^3+b^3+c^3 = 3abc$, maka haruslah $a = b = c$.
2. Identitas Sophie Germain
$$a^4 + 4b^4 = (a^2 + 2b^2)^2 - (2ab)^2 = (a^2 - 2ab + 2b^2)(a^2 + 2ab + 2b^2)$$

Identitas ini membuktikan bahwa bentuk $n^4 + 4^n$ selalu komposit untuk semua bilangan bulat $n > 1$ (soal klasik seleksi OSN).
