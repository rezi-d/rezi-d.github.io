3. Ukuran Penempatan: Kuartil & Boxplot

Eksplorasi pembagian kumpulan data menjadi empat bagian berbobot seimbang melalui kuartil bawah ($Q_1$), kuartil tengah ($Q_2$ / median), dan kuartil atas ($Q_3$). Pelajari formulasi kuartil data kelompok, representasi grafis diagram kotak-garis (*boxplot* / lima serangkai), serta kriteria penentuan pencilan (*outlier*) berdasarkan pagar dalam dan pagar luar jangkauan antarkuartil ($\text{IQR}$).

Poin 1 / 5
1

Kuartil Data Tunggal ($Q_1, Q_2, Q_3$)

Kuartil adalah nilai-nilai pembatas yang membagi sekumpulan data numerik yang telah diurutkan (*terurut menaik*) menjadi empat bagian sama banyak (masing-masing menampung 25% data). Terdapat 3 titik kuartil:

Kuartil Bawah ($Q_1$)

Membatasi 25% data terendah. Setara dengan persentil ke-25 ($P_{25}$).

Kuartil Tengah ($Q_2$)

Membagi data tepat 50% di bawah dan 50% di atas. Identik dengan Median.

Kuartil Atas ($Q_3$)

Membatasi 75% data di bawahnya atau 25% data tertinggi. Setara dengan $P_{75}$.

Formula Penentuan Letak Kuartil Data Tunggal ($n$ Data):

$$\text{Letak } Q_i = \frac{i(n + 1)}{4}, \quad \text{untuk } i = 1, 2, 3$$

Jika hasil perhitungan letak berupa bilangan desimal berpecahan, nilai kuartil ditentukan melalui interpolasi linier antar urutan data terdekat.

Contoh Data Terurut: $3, 5, 7, 8, 10, 11, 14, 15, 18$ ($n = 9$).
  • Letak $Q_1 = \frac{1(9 + 1)}{4} = 2{,}5 \implies Q_1 = x_2 + 0{,}5(x_3 - x_2) = 5 + 0{,}5(7 - 5) = \mathbf{6}$.
  • Letak $Q_2 = \frac{2(9 + 1)}{4} = 5 \implies Q_2 = x_5 = \mathbf{10}$.
  • Letak $Q_3 = \frac{3(9 + 1)}{4} = 7{,}5 \implies Q_3 = x_7 + 0{,}5(x_8 - x_7) = 14 + 0{,}5(15 - 14) = \mathbf{14{,}5}$.
2

Kuartil Data Kelompok (Tabel Distribusi)

Untuk data yang tersusun dalam tabel distribusi frekuensi berkelompok, kuartil ke-$i$ dihitung dengan terlebih dahulu menentukan kelas kuartil yang memuat frekuensi kumulatif ke-$\frac{i}{4}N$, lalu menggunakan interpolasi batas tepi bawah:

Rumus Kuartil Data Kelompok
$$Q_i = L_i + c \cdot \left(\frac{\frac{i \cdot N}{4} - \sum f_{k}}{f_{Q_i}}\right)$$
• $L_i$ = Tepi bawah kelas kuartil ke-$i$ (batas bawah $- 0{,}5$)
• $c$ = Panjang interval kelas (*panjang kelas*)
• $N$ = Total seluruh frekuensi sampel ($\sum f$)
• $\sum f_k$ = Jumlah frekuensi kumulatif sebelum kelas kuartil
• $f_{Q_i}$ = Frekuensi absolut kelas kuartil ke-$i$ itu sendiri
Interval Skor Frekuensi ($f$) Kumulatif ($f_k$) Keterangan Letak ($N = 40$)
41 - 50 4 4 Data ke 1 - 4
51 - 60 8 12 Memuat data ke-10 → Kelas $Q_1$
61 - 70 14 26 Memuat data ke-20 → Kelas Median ($Q_2$)
71 - 80 10 36 Memuat data ke-30 → Kelas $Q_3$
81 - 90 4 40 Data ke 37 - 40

*Contoh $Q_1$: $L_1 = 50{,}5$; $c = 10$; letak $= \frac{1}{4}(40) = 10$; $\sum f_k = 4$; $f_{Q1} = 8 \implies Q_1 = 50{,}5 + 10 \left(\frac{10 - 4}{8}\right) = 50{,}5 + 7{,}5 = \mathbf{58{,}0}$.

3

Diagram Kotak-Garis (Boxplot) & Lima Serangkai

Diagram Kotak-Garis (*Box-and-Whisker Plot*) memvisualisasikan sebaran data secara padat melalui Ringkasan Lima Serangkai (*Five-Number Summary*):

Anatomi Standar Diagram Kotak-Garis:
Panjang Kotak (Box Length): Menggambarkan konsentrasi 50% data di wilayah tengah ($\text{IQR} = Q_3 - Q_1$). Semakin pendek kotak, data di sekitar median semakin homogen.
Panjang Kumis (Whisker Length): Menunjukkan bentangan sebaran ekor data terendah dan tertinggi. Kumis yang asimetris menandakan distribusi data yang menjulur (menceng/skewed).
4

Jangkauan Antarkuartil ($\text{IQR}$) & Deteksi Pencilan (*Outlier*)

Pencilan (*Outlier*) adalah titik data yang nilainya menyimpang secara ekstrem dari mayoritas gugus data lainnya. Statistika modern menggunakan Aturan $1{,}5 \times \text{IQR}$ (Tukey's Fences) untuk mendeteksi outlier secara objektif:

Langkah-Langkah Komputasi Pagar Pencilan:
  1. Hitung Jangkauan Antarkuartil ($\text{IQR}$):
    $$\text{IQR} = Q_3 - Q_1$$
  2. Tentukan Pagar Dalam Bawah ($PD_B$):
    $$PD_B = Q_1 - 1{,}5 \times \text{IQR}$$
  3. Tentukan Pagar Dalam Atas ($PD_A$):
    $$PD_A = Q_3 + 1{,}5 \times \text{IQR}$$
🚨 Kriteria Titik Pencilan (Outlier):

Suatu data $x$ diklasifikasikan sebagai Pencilan Ringan / Luar Biasa jika:

$$x < PD_B \quad \text{atau} \quad x > PD_A$$

Pada boxplot, titik pencilan tidak disambungkan ke whisker, melainkan digambarkan sebagai titik tersendiri (asterisk $*$ atau lingkaran $\circ$) di luar rentang kumis.
