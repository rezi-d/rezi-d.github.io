Poin 1 · Landasan Konseptual

💡 1. Konsep Pola Bilangan, Barisan & Notasi Suku

Definisi Barisan
🔢

Barisan sebagai Fungsi Bilangan Bulat Positif

Dalam kalkulus formal, barisan (sequence) adalah sebuah fungsi $f$ yang domainnya merupakan himpunan bilangan bulat positif $\mathbb{Z}^+ = \{1, 2, 3, 4, \dots\}$. Nilai fungsi $f(1), f(2), f(3), \dots$ dinotasikan sebagai suku-suku berurutan $U_1, U_2, U_3, \dots, U_n$. Indeks $n$ melambangkan posisi/urutan suku, sedangkan $U_n$ adalah nilai numerik suku tersebut.

Ada dua cara umum untuk menyatakan rumus suatu barisan:

1. Rumus Eksplisit ($U_n$ sebagai fungsi $n$):

$U_n = 3n - 1$
Untuk mencari suku ke-$100$, cukup substitusikan $n = 100$:
$U_{100} = 3(100) - 1 = 299$.

2. Rumus Rekursif (Berdasarkan suku sebelumnya):

$U_1 = 2$
$U_n = U_{n-1} + 3 \quad (n \ge 2)$
Setiap suku diperoleh dari suku sebelumnya ditambah $3$.

Poin 2 · Pembuktian Deduktif

⚡ 2. Barisan Aritmetika & Pembuktian Suku ke-$n$

Formula $U_n$

Barisan Aritmetika adalah barisan bilangan di mana selisih antara dua suku yang berurutan selalu konstan. Selisih tetap ini disebut beda ($b$):

$$b = U_n - U_{n-1} = U_2 - U_1 = U_3 - U_2 = \dots$$

Pembuktian Konstruktif Suku ke-$n$:

Suku ke-1 ($n = 1$): $U_1 = a = a + 0 \cdot b$

Suku ke-2 ($n = 2$): $U_2 = a + b = a + 1 \cdot b$

Suku ke-3 ($n = 3$): $U_3 = (a + b) + b = a + 2 \cdot b$

Suku ke-4 ($n = 4$): $U_4 = (a + 2b) + b = a + 3 \cdot b$

Maka untuk suku ke-$n$: $$U_n = a + (n - 1)b$$

Keterangan: $a = U_1$ (suku pertama), $b$ (beda antar suku), $n$ (urutan suku, $n \in \mathbb{Z}^+$).

Poin 3 · Sifat Khusus Aljabar

🔍 3. Suku Tengah ($U_t$) & Teorema Sisipan Bilangan

Sifat Aljabar
Suku Tengah Barisan Aritmetika ($U_t$)

Jika suatu barisan aritmetika memiliki banyak suku ganjil ($n = 2k - 1$), maka terdapat tepat satu suku di tengah:

$$U_t = \frac{a + U_n}{2}$$

Posisi suku tengah berada pada indeks $t = \frac{n + 1}{2}$.

Teorema Sisipan Aritmetika

Jika di antara dua bilangan $x$ dan $y$ disisipkan $k$ buah bilangan baru sehingga membentuk barisan aritmetika baru, maka beda barisan baru ($b'$) adalah:

$$b' = \frac{y - x}{k + 1} = \frac{b_{\text{lama}}}{k + 1}$$

Banyak suku baru menjadi $n' = n + (n - 1)k$.

Poin 4 · Analisis Masalah & Jebakan

🎯 4. Miskonsepsi Beda & Studi Kasus Dua Suku

Studi Kasus
⚠️ Waspada Beda Negatif (Barisan Turun Monoton):

Pada barisan $20, 16, 12, 8, \dots$, bedanya adalah $b = 16 - 20 = -4$ (bukan $+4$). Jika $b < 0$, suku-suku barisan akan semakin mengecil dan pada akhirnya bernilai negatif.

Studi Kasus Eliminasi Aljabar Standar UTBK-SNBT

Diketahui suku ke-$5$ suatu barisan aritmetika adalah $19$ dan suku ke-$11$ adalah $43$. Tentukan suku ke-$25$ barisan tersebut!

• $U_5 = a + 4b = 19$ ... (Persamaan 1)

• $U_{11} = a + 10b = 43$ ... (Persamaan 2)

• Kurangkan (2) dengan (1): $(10b - 4b) = 43 - 19 \implies 6b = 24 \implies \mathbf{b = 4}$.

• Substitusi $b = 4$ ke (1): $a + 4(4) = 19 \implies a + 16 = 19 \implies \mathbf{a = 3}$.

🎉 Maka $U_{25} = a + 24b = 3 + 24(4) = 3 + 96 = \mathbf{99}$.
