Poin 1 · Landasan Konsep & Sejarah

💡 1. Konsep Deret Aritmetika & Trik Penjumlahan Gauss

Trik Gauss
📜

Perbedaan Barisan vs Deret

Jika barisan adalah daftar nilai suku berurutan ($U_1, U_2, U_3, \dots$), maka deret (series) adalah total penjumlahan suku-suku barisan tersebut: $$S_n = U_1 + U_2 + U_3 + \dots + U_n$$ Pada abad ke-18, matematikawan cilik Carl Friedrich Gauss (usia 10 tahun) mengejutkan gurunya saat diminta menjumlahkan $1 + 2 + 3 + \dots + 100$. Gauss menyadari bahwa pasangan ujung-ujung penjumlahan selalu menghasilkan nilai yang sama: $(1 + 100) = 101$, $(2 + 99) = 101$, dst. Terdapat $50$ pasang, sehingga totalnya adalah $50 \times 101 = 5.050$!

Simetri Penjumlahan Maju & Mundur Gauss:
$S_{100} = 1 + 2 + 3 + \dots + 98 + 99 + 100$
$S_{100} = 100 + 99 + 98 + \dots + 3 + 2 + 1$
--------------------------------------------------------- (+)
$2 \cdot S_{100} = \underbrace{101 + 101 + 101 + \dots + 101}_{100 \text{ suku}} = 100 \times 101$
$$S_{100} = \frac{100 \times 101}{2} = 5.050$$
Poin 2 · Konstruksi Rumus Resmi

⚡ 2. Dua Formula Jumlah Deret Aritmetika ($S_n$)

Formula $S_n$

Dengan menggeneralisasi metode simetri Gauss untuk barisan aritmetika sembarang berderajat suku pertama $a$ dan beda $b$, diperoleh dua bentuk rumus baku:

Bentuk 1: Jika $U_n$ Diketahui

Gunakan saat suku awal $a$ dan suku terakhir $U_n$ telah diketahui secara eksplisit:

$$S_n = \frac{n}{2}(a + U_n)$$

Sangat efisien jika soal langsung memberikan nilai batas akhir.

Bentuk 2: Jika Beda ($b$) Diketahui

Substitusikan $U_n = a + (n-1)b$ ke dalam Bentuk 1:

$$S_n = \frac{n}{2}\left(2a + (n - 1)b\right)$$

Bentuk umum paling sering dipakai pada soal pemodelan.

💡 Hubungan Suku Tengah ($U_t$): Karena $U_t = \frac{a + U_n}{2}$, maka untuk banyak suku $n$ ganjil berlaku persamaan ringkas:
$$S_n = n \times U_t$$
Poin 3 · Relasi Diferensial Diskret

🔍 3. Relasi Fundamental: $U_n = S_n - S_{n-1}$

Relasi Deret

Perhatikan dekomposisi penjumlahan suku-suku berikut:

$S_n = U_1 + U_2 + U_3 + \dots + U_{n-1} + U_n$

$S_{n-1} = U_1 + U_2 + U_3 + \dots + U_{n-1}$

$$S_n - S_{n-1} = U_n \quad (n \ge 2)$$

Khusus untuk $n = 1$: $U_1 = S_1$.

Soal Tipe Menentukan $U_n$ dari Rumus $S_n$ Kuadrat

Jumlah $n$ suku pertama suatu deret dirumuskan dengan $S_n = 2n^2 + 5n$. Tentukan rumus suku ke-$n$ dan suku pertama serta bedanya!

$U_n = S_n - S_{n-1}$

$U_n = (2n^2 + 5n) - [2(n-1)^2 + 5(n-1)]$

$U_n = (2n^2 + 5n) - [2(n^2 - 2n + 1) + 5n - 5]$

$U_n = (2n^2 + 5n) - [2n^2 + n - 3] = \mathbf{4n + 3}$

Diperoleh: $a = U_1 = 4(1) + 3 = 7$ dan beda $b = 4$ (koefisien dari $n$).

Poin 4 · Notasi Kalkulus Formal

📐 4. Notasi Sigma ($\sum$) & Sifat-Sifat Penjumlahan

Notasi Sigma

Huruf Yunani kapital $\Sigma$ (sigma) digunakan sebagai simbol universal penjumlahan berantai dari indeks bawah $k = m$ hingga indeks atas $n$:

$$\sum_{k=m}^n f(k) = f(m) + f(m+1) + f(m+2) + \dots + f(n)$$

1. Sifat Linieritas:

$$\sum_{k=1}^n c \cdot a_k = c \sum_{k=1}^n a_k$$

$$\sum_{k=1}^n (a_k \pm b_k) = \sum_{k=1}^n a_k \pm \sum_{k=1}^n b_k$$

2. Penjumlahan Konstanta & Geser Indeks:

$$\sum_{k=1}^n c = n \times c$$

$$\sum_{k=m}^n a_k = \sum_{k=m+p}^{n+p} a_{k-p}$$
