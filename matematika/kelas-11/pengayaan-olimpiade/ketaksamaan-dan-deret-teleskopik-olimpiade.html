⚖️ 1. Ketaksamaan Cauchy-Schwarz & Titu's Lemma

Titu's Lemma

Bagi sembarang bilangan real $a_1, \dots, a_n$ dan $b_1, \dots, b_n$, Ketaksamaan Cauchy-Schwarz (CS) menyatakan:

$$\left(\sum_{i=1}^n a_i^2\right)\left(\sum_{i=1}^n b_i^2\right) \ge \left(\sum_{i=1}^n a_i b_i\right)^2$$
Bentuk Engel / Titu's Lemma (Senjata Emas Pembuktian Pecahan):

Untuk sembarang bilangan real $a_i$ dan bilangan real positif $b_i > 0$:

$$\sum_{i=1}^n \frac{a_i^2}{b_i} \ge \frac{(a_1 + a_2 + \dots + a_n)^2}{b_1 + b_2 + \dots + b_n}$$

Bukti Kilat: Terapkan Cauchy-Schwarz pada vektor $\vec{u} = \left(\frac{a_i}{\sqrt{b_i}}\right)$ dan $\vec{v} = (\sqrt{b_i})$. Hasil kali titik menghasilkan $(a_1 + \dots + a_n)^2$.

💡 Pembuktian Ketaksamaan Nesbitt: Tunjukkan $\frac{a}{b+c} + \frac{b}{c+a} + \frac{c}{a+b} \ge \frac{3}{2}$.
Tulis sebagai $\sum \frac{a^2}{ab+ca} \ge \frac{(a+b+c)^2}{2(ab+bc+ca)}$. Karena $(a+b+c)^2 \ge 3(ab+bc+ca)$, maka nilai minimumnya langsung terbukti $\ge \frac{3}{2}$!

📈 2. Ketaksamaan Jensen & Analisis Konveksitas

f(Σ w_i x_i) ≤ Σ w_i f(x_i)

Suatu fungsi $f(x)$ dikatakan konveks (cekung ke atas) jika turunan keduanya $f''(x) \ge 0$. Ketaksamaan Jensen merumuskan bahwa nilai fungsi dari rata-rata selalu lebih kecil dari rata-rata nilai fungsinya:

$$f\left(\frac{x_1 + x_2 + \dots + x_n}{n}\right) \le \frac{f(x_1) + f(x_2) + \dots + f(x_n)}{n}$$
Fungsi Cekung (Konkaf, $f''(x) \le 0$):

Tanda ketaksamaan berbalik arah! Nilai fungsi dari rata-rata menjadi maksimum: $$f\left(\frac{\sum x_i}{n}\right) \ge \frac{\sum f(x_i)}{n}$$

Aplikasi pada Sinus Segitiga:

Karena $f(x) = \sin x$ konkaf pada $(0, \pi)$, maka: $$\sin\left(\frac{A+B+C}{3}\right) \ge \frac{\sin A + \sin B + \sin C}{3}$$ $$\sin 60^\circ = \frac{\sqrt{3}}{2} \implies \sin A + \sin B + \sin C \le \frac{3\sqrt{3}}{2}$$

🔭 3. Trik Penjumlahan Deret Teleskopik

Σ (a_{k+1} - a_k)

Prinsip teleskopik mengubah deret panjang menjadi selisih dua suku bersebelahan, sehingga seluruh suku di tengah saling meniadakan (cancel out):

1. Teleskopik Pecahan Parsial

$$\frac{1}{k(k+2)} = \frac{1}{2}\left(\frac{1}{k} - \frac{1}{k+2}\right)$$ Deret tak hingga menyisakan suku-suku awal: $$\sum_{k=1}^\infty \frac{1}{k(k+2)} = \frac{1}{2}\left(1 + \frac{1}{2}\right) = \frac{3}{4}$$

2. Teleskopik Deret Arctan

Gunakan identitas $\arctan\left(\frac{x - y}{1 + xy}\right) = \arctan x - \arctan y$: $$\arctan\left(\frac{1}{k^2 + k + 1}\right) = \arctan(k+1) - \arctan(k)$$ $$\sum_{k=1}^\infty \arctan\left(\frac{1}{k^2 + k + 1}\right) = \frac{\pi}{2} - \frac{\pi}{4} = \frac{\pi}{4}$$

💡 4. Trik Homogenisasi & Normalisasi

Normalisasi a + b + c = 1

Ketaksamaan $f(a, b, c) \ge 0$ disebut homogen derajat $d$ jika $f(ta, tb, tc) = t^d f(a, b, c)$ untuk sembarang skalar $t > 0$. Sifat homogen memberikan kebebasan mutlak bagi kita untuk menetapkan satu asumsi pembantu (Normalisasi):

Pilihan Asumsi Normalisasi yang Umum:
  • Normalisasi Penjumlahan: Tetapkan $a + b + c = 1$ atau $a + b + c = 3$.
  • Normalisasi Perkalian: Tetapkan $abc = 1$.
  • Normalisasi Kuadrat: Tetapkan $a^2 + b^2 + c^2 = 1$.

Mengapa ini sah? Karena jika $a + b + c = S \ne 1$, kita cukup mengganti variabel menjadi $a' = a/S, b' = b/S, c' = c/S$ tanpa mengubah kebenaran ketaksamaan!
