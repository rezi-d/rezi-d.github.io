Poin 1 · Hubungan Simetris Akar

🧮 1. Teorema Vieta untuk Polinomial Derajat $n \ge 3$

Vieta Formula

Diberikan polinomial derajat $n$: $P(x) = a_n x^n + a_{n-1} x^{n-1} + a_{n-2} x^{n-2} + \dots + a_1 x + a_0 = 0$ dengan akar-akar kompleks $r_1, r_2, \dots, r_n$. Teorema Vieta merumuskan fungsi simetris elementer $s_k$:

Jumlah 1 Akar ($s_1$)
$$s_1 = \sum_{i=1}^n r_i = -\frac{a_{n-1}}{a_n}$$
Jumlah Hasil Kali 2 Akar ($s_2$)
$$s_2 = \sum_{i < j} r_i r_j = \frac{a_{n-2}}{a_n}$$
Jumlah Hasil Kali $k$ Akar ($s_k$)
$$s_k = (-1)^k \frac{a_{n-k}}{a_n}$$
Hasil Kali Seluruh Akar ($s_n$)
$$s_n = \prod_{i=1}^n r_i = (-1)^n \frac{a_0}{a_n}$$
💡 Bentuk Simetris yang Wajib Dihafal di Luar Kepala:
Jumlah Kuadrat:
$\sum r_i^2 = s_1^2 - 2s_2$
Jumlah Kebalikan Akar:
$\sum \frac{1}{r_i} = \frac{s_{n-1}}{s_n} = -\frac{a_1}{a_0}$

Trik Olimpiade: Eksploitasi Simetri Tanpa Mencari Akar

Strategi membaca koefisien Vieta, eliminasi variabel, & trik pembalik akar

Studi Kasus Soal: Diberikan persamaan polinomial kubik $x^3 - 4x^2 + 2x - 7 = 0$ dengan akar-akar $a, b,$ dan $c$. Hitung nilai dari jumlahan kuadrat $a^2 + b^2 + c^2$ dan hasil kali pergeseran $(a+1)(b+1)(c+1)$.

⚠️ Jebakan Terbesar: Tergoda Mencari Nilai Akar Eksplisit

Peserta yang panik sering kali mencoba mencari akar dengan uji faktor rasional $pm 1, pm 7$ atau rumus Cardano.

Fakta di Lapangan: Polinomial di atas tidak memiliki akar rasional! Ketiga akarnya berupa kombinasi irasional dan kompleks yang sangat mengerikan jika dihitung terpisah. Juri olimpiade sengaja mendesain soal ini agar diselesaikan murni melalui struktur simetris koefisien.

🧠 Narasi Penjelasan & Intuisi Langkah demi Langkah:
  • 1
    Ekstraksi Koefisien Simetris Dasar (Vieta):
    Dari $P(x) = x^3 - 4x^2 + 2x - 7$, kita peroleh: $$s_1 = a+b+c = -(-4)/1 = 4, quad s_2 = ab+bc+ca = 2/1 = 2, quad s_3 = abc = -(-7)/1 = 7$$
  • 2
    Hitung Jumlahan Kuadrat Tanpa Mengetahui Akarnya:
    Gunakan identitas kuadrat sempurna: $(a+b+c)^2 = a^2 + b^2 + c^2 + 2(ab+bc+ca)$. Maka: $a^2 + b^2 + c^2 = s_1^2 - 2s_2 = 4^2 - 2(2) = 16 - 4 = mathbf{12}$. Tuntas dalam 1 baris!
  • 3
    Trik Evaluasi Nilai Khusus untuk $(a+1)(b+1)(c+1)$:
    Jangan kalikan satu per satu! Perhatikan bahwa $(x-a)(x-b)(x-c) = P(x)$.
    Jika kita masukkan $x = -1$, maka: $$(-1-a)(-1-b)(-1-c) = P(-1) implies -(a+1)(b+1)(c+1) = P(-1)$$ Sehingga $(a+1)(b+1)(c+1) = -P(-1) = -[(-1)^3 - 4(-1)^2 + 2(-1) - 7] = -[-1 - 4 - 2 - 7] = -(-14) = mathbf{14}$!
⚡ Trik Kilat: Menghitung Kebalikan Akar via Pembalikan Koefisien

Jika ditanyakan $ rac{1}{a} + rac{1}{b} + rac{1}{c}$, lakukan transformasi $y = rac{1}{x}$. Persamaan polinomial bagi $y$ diperoleh cukup dengan membalik urutan koefisien: $$-7y^3 + 2y^2 - 4y + 1 = 0 iff 7y^3 - 2y^2 + 4y - 1 = 0$$ Jumlahan akarnya adalah $y_1 + y_2 + y_3 = -(-2)/7 = mathbf{ rac{2}{7}}$. Sangat instan dan bebas risiko salah samakan penyebut!

Poin 2 · Senjata Rahasia Olimpiade

⚡ 2. Rumus Jumlah Newton (Newton's Sums)

P_k = Σ r_i^k

Ketika diminta mencari nilai pangkat tinggi dari akar-akar polinomial seperti $r_1^5 + r_2^5 + r_3^5$, menghitung manual akan memakan waktu berjam-jam. Newton's Sums memberikan hubungan rekursif elegan antara jumlah pangkat $P_k = \sum_{i=1}^n r_i^k$ dengan koefisien polinomial monik $x^n + a_{n-1} x^{n-1} + \dots + a_0 = 0$:

$$P_1 + a_{n-1} = 0$$

$$P_2 + a_{n-1} P_1 + 2a_{n-2} = 0$$

$$P_3 + a_{n-1} P_2 + a_{n-2} P_1 + 3a_{n-3} = 0$$

Dan untuk sembarang $k \ge n$:

$$P_k + a_{n-1} P_{k-1} + a_{n-2} P_{k-2} + \dots + a_0 P_{k-n} = 0$$

Studi Kasus: $x^3 - x - 1 = 0$ dengan akar $a, b, c$. Cari $a^5 + b^5 + c^5$!

• Persamaan: $x^3 = x + 1 \implies P_k = P_{k-2} + P_{k-3}$ untuk $k \ge 3$.

• $P_0 = 1 + 1 + 1 = 3$

• $P_1 = s_1 = 0$

• $P_2 = s_1^2 - 2s_2 = 0 - 2(-1) = 2$

• $P_3 = P_1 + P_0 = 0 + 3 = 3$

• $P_4 = P_2 + P_1 = 2 + 0 = 2$

• $P_5 = P_3 + P_2 = 3 + 2 = 5$

⚡

Trik Olimpiade: Senjata Rekursif Newton's Sums

Menembus jumlahan pangkat tinggi $P_k = sum r_i^k$ tanpa ekspansi multinomial

Studi Kasus Soal: Diberikan persamaan $x^3 - 2x^2 + x - 3 = 0$ dengan akar-akar $p, q, r$. Tentukan nilai dari $p^4 + q^4 + r^4$.

⚠️ Mengapa Aljabar Konvensional Membuang Waktu?

Menghitung $p^4 + q^4 + r^4$ dengan menguadratkan $(p^2+q^2+r^2)^2$ menuntut Anda mencari suku silang $(pq)^2 + (qr)^2 + (rp)^2$, yang kembali memerlukan penjabaran panjang. Pada soal berpangkat 5 atau 6, cara ini dijamin gagal selesai tepat waktu.

🧠 Narasi Logika Eksekusi Rekursi Newton:
  • 1
    Ubah Persamaan Menjadi Relasi Rekursi:
    Karena $x^3 = 2x^2 - x + 3$, kalikan dengan $x^{k-3}$ untuk mendapatkan relasi barisan: $$P_k = 2P_{k-1} - P_{k-2} + 3P_{k-3} quad ( ext{untuk } k ge 3)$$
  • 2
    Siapkan Nilai Awal yang Benar (Awas $P_0$!):
    • $P_0 = p^0 + q^0 + r^0 = 1 + 1 + 1 = mathbf{3}$ (Derajat polinomial, bukan 0!)
    • $P_1 = p + q + r = -(-2)/1 = mathbf{2}$
    • $P_2 = P_1^2 - 2s_2 = 2^2 - 2(1) = 4 - 2 = mathbf{2}$
  • 3
    Melompat ke $P_3$ dan $P_4$:
    $$P_3 = 2P_2 - P_1 + 3P_0 = 2(2) - 2 + 3(3) = 4 - 2 + 9 = mathbf{11}$$ $$P_4 = 2P_3 - P_2 + 3P_1 = 2(11) - 2 + 3(2) = 22 - 2 + 6 = mathbf{26}$$
✓ Nilai $p^4 + q^4 + r^4 = mathbf{26}$ didapatkan hanya dengan aritmetika dasar 1 digit tanpa risiko salah aljabar!
Poin 3 · Polinomial Bilangan Bulat ℤ[x]

🛡️ 3. Sifat Keterbagian Polinomial Bulat (a - b) | (P(a) - P(b))

(a - b) | (P(a) - P(b))

Bagi sembarang polinomial dengan koefisien bilangan bulat $P(x) \in \mathbb{Z}[x]$, berlaku teorema keterbagian yang merupakan salah satu senjata paling sering dipakai dalam pembuktian OSN:

$$(a - b) \mid [P(a) - P(b)], \quad \forall a, b \in \mathbb{Z}, \, a \ne b$$
Bukti Singkat:

Setiap suku $a_k(a^k - b^k)$ selalu habis dibagi oleh $(a - b)$ karena identitas aljabar: $$a^k - b^k = (a - b)(a^{k-1} + a^{k-2}b + \dots + b^{k-1})$$

Aplikasi Teorema Siklik:

Buktikan tidak ada polinomial bulat $P(x)$ yang memenuhi $P(a) = b, P(b) = c, P(c) = a$ untuk bilangan bulat berbeda $a, b, c$.
Argumen: $(a - b) \mid (b - c) \mid (c - a) \mid (a - b) \implies |a - b| = |b - c| = |c - a|$, kontradiksi saat dijumlahkan!

📜 Kriteria Eisenstein (Ketakteruraian / Irreducibility):

Polinomial $P(x) = a_n x^n + \dots + a_0 \in \mathbb{Z}[x]$ tidak dapat difaktorkan atas bilangan rasional $\mathbb{Q}$ jika ada bilangan prima $p$ sedemikian sehingga: $$p \nmid a_n, \quad p \mid a_{n-1}, \dots, a_0, \quad \text{dan} \quad p^2 \nmid a_0$$

🛡️

Trik Olimpiade: Keterbagian Polinomial Bulat & Pembuktian Kontradiksi

Pemanfaatan relasi $(a-b) mid (P(a)-P(b))$ pada permasalahan bilangan bulat

Studi Kasus Soal (OSN-K): Tentukan seluruh bilangan bulat $n$ sedemikian sehingga $n - 2$ membagi habis nilai dari $P(n) = n^3 - 2n + 7$.

🧠 Narasi Reduksi ke Konstanta Numerik:
  • 1
    Gunakan Teorema Sisa / Keterbagian:
    Berdasarkan teorema keterbagian: $(n - 2)$ selalu membagi habis $[P(n) - P(2)]$.
  • 2
    Hitung Nilai $P(2)$ Secara Eksplisit:
    $$P(2) = 2^3 - 2(2) + 7 = 8 - 4 + 7 = mathbf{11}$$ Karena $(n - 2) mid [P(n) - 11]$, maka $(n - 2) mid P(n)$ jika dan hanya jika $(n - 2)$ membagi habis $11$!
  • 3
    Daftar Seluruh Faktor Pembagi Bulat dari 11:
    Karena 11 bilangan prima, faktor bulatnya hanyalah ${pm 1, pm 11}$.
    • $n - 2 = 1 implies n = 3$
    • $n - 2 = -1 implies n = 1$
    • $n - 2 = 11 implies n = 13$
    • $n - 2 = -11 implies n = -9$
    Himpunan solusi lengkap: $n in {-9, 1, 3, 13}$.
💎 Prinsip Kontradiksi Siklik pada OSN-P:

Jika suatu soal menyatakan $P(a) = b, P(b) = c, P(c) = a$ untuk $a,b,c in mathbb{Z}$ berbeda, maka: $$(a-b) mid (b-c) mid (c-a) mid (a-b) implies |a-b| = |b-c| = |c-a| = d > 0$$ Namun jumlahan selisih $(a-b) + (b-c) + (c-a) = 0$. Tiga bilangan bernilai mutlak sama tidak mungkin berjumlah 0 (karena $pm d pm d pm d e 0$). Terbukti mustahil secara mutlak!

🎯 4. Trik Polinomial Monik & Fungsi Selisih Pembantu

Q(x) = P(x) - g(x)

Bila diberikan nilai polinomial di beberapa titik berurutan, trik standar olimpiade adalah membuat fungsi selisih $Q(x) = P(x) - g(x)$ sehingga titik-titik tersebut menjadi akar dari $Q(x)$:

Contoh Klasik: Diberikan polinomial monik berderajat 4, $P(x)$, dengan $P(1) = 10, P(2) = 20, P(3) = 30, P(4) = 40$. Tentukan nilai $P(5)$!
Langkah 1: Amati Pola Nilai
Perhatikan bahwa $P(x) = 10x$ untuk $x = 1, 2, 3, 4$.
Langkah 2: Bentuk Polinomial Selisih $Q(x)$
Definisikan $Q(x) = P(x) - 10x$. Karena $P(x)$ berderajat 4 dan monik (koefisien utama 1), maka $Q(x)$ juga berderajat 4 monik dengan akar $1, 2, 3, 4$: $$Q(x) = (x - 1)(x - 2)(x - 3)(x - 4)$$
Langkah 3: Hitung $P(5)$ dengan Cepat
$$P(5) - 10(5) = Q(5) = (5 - 1)(5 - 2)(5 - 3)(5 - 4)$$ $$P(5) - 50 = (4)(3)(2)(1) = 24 \implies P(5) = 74$$
🏆 Wawasan Master: Trik ini menghindari sistem persamaan linier 4 variabel yang sangat menyita waktu dan rawan kekeliruan perhitungan!

Trik Olimpiade: Rekayasa Fungsi Selisih Pembantu Q(x)

Mengonstruksi akar-akar buatan untuk memusnahkan sistem persamaan linear

Studi Kasus Soal Master: Diberikan polinomial monik berderajat 3, $P(x)$, dengan $P(1) = 1, P(2) = rac{1}{2}, P(3) = rac{1}{3}$. Tentukan nilai dari $P(4)$!

⚠️ Perangkap Pecahan: Jangan Masukkan Langsung ke ax³ + bx² + cx + d

Pola nilai $1, rac{1}{2}, rac{1}{3}$ menggoda peserta untuk membuat eliminasi pecahan yang sangat rentan keliru. Trik olimpiade adalah menghilangkan penyebut variabel terlebih dahulu!

🧠 Konstruksi Polinomial Pembantu Berderajat 4:
  • 1
    Perhatikan Hubungan Input dan Output:
    Untuk $x = 1, 2, 3$, berlaku hubungan $x cdot P(x) = 1 iff x cdot P(x) - 1 = 0$.
  • 2
    Definisikan Fungsi Baru $H(x)$:
    Misalkan $H(x) = x cdot P(x) - 1$.
    Karena $P(x)$ berderajat 3 monik, maka $H(x)$ berderajat 4 monik dengan akar-akar $1, 2, 3$, dan akar ke-4 kita misalkan $r$: $$H(x) = (x - 1)(x - 2)(x - 3)(x - r)$$
  • 3
    Cari Akar Keempat ($r$) dengan Memasukkan $x = 0$:
    $$H(0) = 0 cdot P(0) - 1 = -1$$ Di sisi lain: $H(0) = (0-1)(0-2)(0-3)(0-r) = (-1)(-2)(-3)(-r) = 6r$.
    Maka $6r = -1 implies r = - rac{1}{6}$.
  • 4
    Hitung $P(4)$ dengan Mudah:
    $$4 cdot P(4) - 1 = H(4) = (4-1)(4-2)(4-3)left(4 - left(- rac{1}{6} ight) ight) = (3)(2)(1)left( rac{25}{6} ight) = 25$$ $$4 cdot P(4) = 26 implies P(4) = rac{26}{4} = mathbf{ rac{13}{2}}$$
