3. Segi Empat Tali Busur & Sudut Dua Tali Busur

Pelajari karakteristik unik segi empat tali busur (cyclic quadrilateral) di mana sudut-sudut yang saling berhadapan selalu berjumlah $180^\circ$, pembuktian sudut luar, teorema perpotongan dua tali busur di dalam lingkaran ($\frac{1}{2}(\text{busur}_1 + \text{busur}_2)$) dan di luar lingkaran ($\frac{1}{2}(\text{busur}_{\text{jauh}} - \text{busur}_{\text{dekat}})$).

Poin 1 / 5
Poin 1 · Landasan Geometris

🛡️ Hakikat Segi Empat Tali Busur (Cyclic Quadrilateral)

\angle A + \angle C = 180^\circ
⭕

Definisi Segi Empat Siklik

Segi empat tali busur (disebut juga segi empat siklik atau *cyclic quadrilateral*) adalah bangun segi empat yang keempat titik sudutnya terletak tepat pada garis keliling sebuah lingkaran. Setiap sisi dari segi empat ini merupakan tali busur lingkaran tersebut.

Teorema Pokok: Sudut-Sudut Berhadapan Saling Bersuplemen

Pada setiap segi empat tali busur, jumlah dua sudut yang saling berhadapan adalah selalu tepat $180^\circ$ (bersuplemen / berpelurus):

$$\angle A + \angle C = 180^\circ$$
$$\angle B + \angle D = 180^\circ$$
Pembuktian Analitis Melalui Teorema Sudut Keliling:

Sudut $\angle A$ adalah sudut keliling yang menghadap busur $\stackrel{\frown}{BCD}$, sehingga $\angle A = \frac{1}{2} \times \text{ukuran busur } BCD$.
Sudut $\angle C$ adalah sudut keliling yang menghadap busur $\stackrel{\frown}{BAD}$, sehingga $\angle C = \frac{1}{2} \times \text{ukuran busur } BAD$.
Karena busur $BCD$ dan busur $BAD$ bersama-sama membentuk satu keliling lingkaran utuh ($360^\circ$), maka:

$$\angle A + \angle C = \frac{1}{2}(\text{busur } BCD + \text{busur } BAD) = \frac{1}{2}(360^\circ) = 180^\circ \quad \text{(Q.E.D.)}$$

Poin 2 · Sifat-Sifat Lanjutan

📐 Sudut Luar Segi Empat Siklik & Teorema Ptolemy

Teorema Lanjutan

Teorema Sudut Luar Segi Empat Tali Busur

Besar sudut luar yang dibentuk oleh perpanjangan salah satu sisi segi empat tali busur adalah sama besar dengan sudut dalam yang berhadapan langsung dengannya:

$$\angle \text{Luar } C = \angle A$$

Penjelasan Logis: Sudut dalam $C$ dan sudut luar $C$ saling berpelurus ($\angle C + \angle \text{Luar } C = 180^\circ$). Karena kita sudah tahu bahwa $\angle C + \angle A = 180^\circ$, maka pasti $\angle \text{Luar } C = \angle A$!

Pengayaan HOTS: Teorema Ptolemy (Hubungan Panjang Sisi & Diagonal) Olimpiade / SNBT

Pada segi empat tali busur $ABCD$, perkalian panjang kedua diagonalnya ($AC$ dan $BD$) sama dengan jumlah perkalian sisi-sisi yang saling berseberangan:

$$AC \cdot BD = (AB \cdot CD) + (BC \cdot AD)$$
Poin 3 · Interseksi Dua Tali Busur

✂️ Sudut Antara Dua Tali Busur (Di Dalam vs Di Luar Lingkaran)

\frac{1}{2}(\text{busur}_1 \pm \text{busur}_2)
Kasus 1: Dua Tali Busur Berpotongan DI DALAM Lingkaran

Jika dua tali busur $AB$ dan $CD$ berpotongan di titik $E$ di dalam lingkaran, besar sudut perpotongannya adalah setengah dari JUMLAH dua busur yang berada di depan dan di belakang sudut tersebut:

$$\angle AED = \frac{1}{2}(\text{busur } \stackrel{\frown}{AD} + \text{busur } \stackrel{\frown}{BC})$$
Kasus 2: Perpanjangan Dua Tali Busur Berpotongan DI LUAR Lingkaran

Jika perpanjangan dua tali busur (garis sekan) berpotongan di titik $P$ di luar lingkaran, besar sudut yang terbentuk adalah setengah dari SELISIH busur besar (jauh) dikurangi busur kecil (dekat):

$$\angle P = \frac{1}{2}(\text{busur}_{\text{jauh}} - \text{busur}_{\text{dekat}})$$
🧠 Jembatan Keledai Memori:
Potong di DALAM $\rightarrow$ bertambah akrab $\rightarrow$ gunakan JUMLAH ($+$).
Potong di LUAR $\rightarrow$ berjauhan $\rightarrow$ gunakan SELISIH ($-$).
Poin 4 · Penguatan Aplikasi Analitis

📝 Contoh Soal Bertahap: Aljabar Sudut & Interseksi Busur

Bedah Soal
Tingkat Menengah: Aljabar Sudut Berhadapan Segi Empat Siklik

Diketahui segi empat tali busur $ABCD$. Jika besar $\angle A = (3x + 15)^\circ$ dan sudut yang berhadapan dengannya $\angle C = (2x + 25)^\circ$, tentukan besar sudut $\angle A$ dan $\angle C$!

Langkah 1: Sifat Sudut Berhadapan Berjumlah $180^\circ$

$$\angle A + \angle C = 180^\circ$$

$$(3x + 15) + (2x + 25) = 180$$

$$5x + 40 = 180 \implies 5x = 140 \implies x = 28$$

Langkah 2: Evaluasi Besar Masing-Masing Sudut:

$$\angle A = 3(28) + 15 = 84 + 15 = 99^\circ$$

$$\angle C = 2(28) + 25 = 56 + 25 = 81^\circ$$

Verifikasi: $99^\circ + 81^\circ = 180^\circ$ (Tepat!).

Tingkat HOTS: Sudut Perpotongan Dua Sekan di Luar Lingkaran

Dua garis sekan berpotongan di titik $P$ di luar lingkaran dan membentuk sudut $\angle P = 36^\circ$. Garis tersebut memotong lingkaran menghasilkan busur kecil $AB = 48^\circ$ dan busur besar $CD$. Tentukan besar sudut pusat yang menghadap busur besar $CD$!

Langkah 1: Gunakan Formula Potong Luar

$$\angle P = \frac{1}{2}(\text{busur } CD - \text{busur } AB)$$

$$36^\circ = \frac{1}{2}(\text{busur } CD - 48^\circ)$$

Kalikan kedua ruas dengan $2$:

$$72^\circ = \text{busur } CD - 48^\circ \implies \text{busur } CD = 72^\circ + 48^\circ = 120^\circ$$

Besar sudut pusat yang menghadap busur besar $CD$ adalah sama dengan ukuran busurnya, yaitu $120^\circ$.
