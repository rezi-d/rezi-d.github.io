2. Operasi Aljabar pada Fungsi & Daerah Asalnya

Dua fungsi atau lebih dapat digabungkan melalui operasi aljabar aritmatika (penjumlahan, pengurangan, perkalian, dan pembagian). Namun, fungsi hasil operasi tersebut hanya terdefinisi pada irisan daerah asal fungsi-fungsi pembentuknya ($D_f \cap D_g$), ditambah syarat khusus penyebut tidak boleh nol pada pembagian fungsi.

Poin 1 / 5
Poin 1 · Operasi Linier Fungsi

➕ Penjumlahan & Pengurangan Fungsi Serta Irisan Domain

D_{f \pm g} = D_f \cap D_g
💡

Ide Intuitif: Output Ganda pada Input yang Sama

Bayangkan dua sensor terpisah: sensor $f$ mengukur temperatur ruangan, dan sensor $g$ mengukur panas dari radiator. Jika kita ingin mengetahui total panas ruangan $(f+g)(x)$, kita harus memasukkan nilai waktu $x$ yang valid untuk kedua sensor sekaligus. Jika sensor $g$ rusak pada interval waktu tertentu, total panas gabungan tentu mustahil dihitung pada interval tersebut. Inilah mengapa domain fungsi gabungan adalah irisan ($D_f \cap D_g$)!

Definisi Formal Operasi Jumlah & Selisih

Diberikan dua fungsi real $f: D_f \rightarrow \mathbb{R}$ dan $g: D_g \rightarrow \mathbb{R}$. Penjumlahan $(f + g)$ dan pengurangan $(f - g)$ didefinisikan sebagai fungsi baru dengan aturan:

$$(f + g)(x) = f(x) + g(x)$$
$$(f - g)(x) = f(x) - g(x)$$

Daerah Asal (Domain): Fungsi $(f + g)$ dan $(f - g)$ hanya terdefinisi pada himpunan bilangan real $x$ yang menjadi anggota dari domain $f$ sekaligus domain $g$:

$$D_{f+g} = D_{f-g} = D_f \cap D_g$$
Contoh Terarah: Kasus Polinomial & Bentuk Akar

Diketahui $f(x) = x^2 - 4$ dan $g(x) = \sqrt{x - 1}$. Tentukan rumus $(f - g)(x)$ dan daerah asalnya!

Langkah 1: Tentukan domain masing-masing fungsi

  • $f(x) = x^2 - 4$ adalah polinomial kuadrat, sehingga $D_f = \mathbb{R} = (-\infty, \infty)$.
  • $g(x) = \sqrt{x - 1}$ adalah fungsi irasional (akar genap), sehingga syaratnya adalah radicand non-negatif: $x - 1 \ge 0 \Rightarrow x \ge 1$. Maka $D_g = [1, \infty)$.

Langkah 2: Tentukan rumus aljabar $(f - g)(x)$

$$(f - g)(x) = f(x) - g(x) = x^2 - 4 - \sqrt{x - 1}$$

Langkah 3: Tentukan irisan domain

$$D_{f - g} = D_f \cap D_g = (-\infty, \infty) \cap [1, \infty) = [1, \infty) = \{x \in \mathbb{R} \mid x \ge 1\}$$

Poin 2 · Perkalian Fungsi & Skalar

✖️ Perkalian Dua Fungsi & Perkalian Konstanta Skalar

(f \cdot g)(x)

Selain dijumlahkan atau dikurangkan, dua fungsi dapat dikalikan satu sama lain secara titik demi titik (*pointwise multiplication*). Perkalian fungsi menghasilkan nilai output yang merupakan hasil kali dari output masing-masing fungsi pada input yang sama:

$$(f \cdot g)(x) = f(x) \cdot g(x)$$
$$(k \cdot f)(x) = k \cdot f(x), \quad k \in \mathbb{R}$$

Analisis Daerah Asal: Sama halnya dengan penjumlahan, kedua fungsi harus terdefinisi serempak pada input $x$. Jadi daerah asal perkalian fungsi adalah irisan dari kedua domain:

$$D_{f \cdot g} = D_f \cap D_g \quad \text{dan} \quad D_{k \cdot f} = D_f$$
Contoh Analitis: Perkalian Dua Fungsi Bentuk Akar

Diketahui fungsi $f(x) = \sqrt{4 - x}$ dan $g(x) = \sqrt{x + 2}$. Tentukan aturan fungsi $(f \cdot g)(x)$ beserta domain asalnya!

1. Evaluasi Domain Masing-Masing:

Syarat $f(x)$: $4 - x \ge 0 \Rightarrow x \le 4$. Jadi $D_f = (-\infty, 4]$.

Syarat $g(x)$: $x + 2 \ge 0 \Rightarrow x \ge -2$. Jadi $D_g = [-2, \infty)$.

2. Bentuk Hasil Perkalian:

$$(f \cdot g)(x) = \sqrt{4 - x} \cdot \sqrt{x + 2} = \sqrt{(4 - x)(x + 2)} = \sqrt{-x^2 + 2x + 8}$$

3. Tentukan Irisan Domain:

$$D_{f \cdot g} = D_f \cap D_g = (-\infty, 4] \cap [-2, \infty) = [-2, 4]$$

Peringatan Penting (Jebakan Aljabar): Jangan langsung mencari domain dari rumus gabungan $\sqrt{-x^2 + 2x + 8}$ tanpa memeriksa domain asal! Dalam aljabar bilangan real, sifat $\sqrt{a} \cdot \sqrt{b} = \sqrt{ab}$ hanya berlaku jika $a \ge 0$ dan $b \ge 0$. Domain fungsi operasi harus selalu diturunkan dari irisan domain asal.
Poin 3 · Pembagian Fungsi Rasional

➗ Pembagian Fungsi & Syarat Mutlak Penyebut Non-Nol

g(x) \neq 0

Pembagian antara dua fungsi menghasilkan fungsi kuosien (hasil bagi):

$$\left(\frac{f}{g}\right)(x) = \frac{f(x)}{g(x)}$$

Pada operasi pembagian, terdapat dua lapisan syarat yang wajib dipenuhi:

  1. Nilai $x$ harus berada pada irisan domain kedua fungsi ($x \in D_f \cap D_g$).
  2. Fungsi pembagi pada penyebut tidak boleh bernilai nol ($g(x) \neq 0$). Nilai $x$ yang menyebabkan $g(x) = 0$ harus dikeluarkan dari himpunan domain!
$$D_{f/g} = \{x \in \mathbb{R} \mid x \in D_f \cap D_g \text{ dan } g(x) \neq 0\} = (D_f \cap D_g) \setminus \{x \mid g(x) = 0\}$$
Kasus Kritis: Penyederhanaan Aljabar vs Domain Asli

Misalkan $f(x) = x^2 - 9$ dan $g(x) = x - 3$. Tentukan rumus $\left(\frac{f}{g}\right)(x)$ dan domain aslinya!

Langkah 1: Perhatikan penyebut sebelum disederhanakan!

Fungsi $f(x)$ memiliki $D_f = \mathbb{R}$. Fungsi $g(x)$ memiliki $D_g = \mathbb{R}$.

Syarat pembagian: penyebut $g(x) \neq 0 \Rightarrow x - 3 \neq 0 \Rightarrow x \neq 3$.

Maka domain dari $\frac{f}{g}$ adalah: $$D_{f/g} = \mathbb{R} \setminus \{3\} = (-\infty, 3) \cup (3, \infty)$$

Langkah 2: Penyederhanaan Aljabar:

$$\left(\frac{f}{g}\right)(x) = \frac{x^2 - 9}{x - 3} = \frac{(x - 3)(x + 3)}{x - 3} = x + 3, \quad \text{untuk } x \neq 3$$

💡 Makna Geometris: Grafik dari $\left(\frac{f}{g}\right)(x)$ berupa garis lurus $y = x + 3$, tetapi memiliki lubang (titik berlubang/hole) pada koordinat $(3, 6)$ karena $x = 3$ tidak termasuk ke dalam domain fungsi hasil bagi!

Poin 4 · Penguatan Konsep Bertingkat

📝 Contoh Soal Bertahap: Dasar, Menengah & HOTS

Bedah Soal
Tingkat Menengah: Kombinasi Pecahan & Akar

Diketahui $f(x) = \frac{1}{x - 2}$ dan $g(x) = \sqrt{x + 1}$. Tentukan rumus $(f + g)(x)$ dan tentukan apakah $x = 2$ dan $x = -2$ berada dalam domain $(f + g)$!

Pembahasan:

1. Rumus aljabar: $$(f + g)(x) = \frac{1}{x - 2} + \sqrt{x + 1} = \frac{1 + (x - 2)\sqrt{x + 1}}{x - 2}$$

2. Domain $f$: penyebut $x - 2 \neq 0 \Rightarrow x \neq 2$, sehingga $D_f = \mathbb{R} \setminus \{2\}$.

3. Domain $g$: bentuk akar $x + 1 \ge 0 \Rightarrow x \ge -1$, sehingga $D_g = [-1, \infty)$.

4. Domain irisan: $$D_{f+g} = D_f \cap D_g = [-1, \infty) \setminus \{2\} = [-1, 2) \cup (2, \infty)$$

Kesimpulan:

  • $x = -2 \notin D_{f+g}$ karena $-2 < -1$ (menyebabkan nilai di dalam akar negatif).
  • $x = 2 \notin D_{f+g}$ karena menyebabkan penyebut bernilai nol (tak terdefinisi).
Tingkat HOTS: Domain Pembagian Dua Fungsi Irasional

Diketahui fungsi $f(x) = \sqrt{9 - x^2}$ dan $g(x) = \sqrt{x^2 - x - 2}$. Tentukan daerah asal fungsi $\left(\frac{f}{g}\right)(x)$ dalam bentuk notasi interval!

Langkah 1: Syarat Pembilang ($f(x)$)

$$9 - x^2 \ge 0 \Rightarrow x^2 \le 9 \Rightarrow -3 \le x \le 3 \implies D_f = [-3, 3]$$

Langkah 2: Syarat Penyebut ($g(x)$)

Karena $g(x)$ berada pada posisi penyebut, nilai di dalam akar harus lebih dari nol secara tegas ($> 0$), bukan $\ge 0$:

$$x^2 - x - 2 > 0 \Rightarrow (x - 2)(x + 1) > 0$$

Pembuat nol: $x = -1$ dan $x = 2$. Melalui uji garis bilangan bertanda, diperoleh solusi:

$$x < -1 \quad \text{atau} \quad x > 2$$

Langkah 3: Irisan Himpunan Solusi

$$D_{f/g} = [-3, 3] \cap ((-\infty, -1) \cup (2, \infty)) = [-3, -1) \cup (2, 3]$$

Jawaban akhir: Daerah asal $\left(\frac{f}{g}\right)(x)$ adalah $[-3, -1) \cup (2, 3]$. Perhatikan tanda kurung siku (inklusif) pada $-3$ dan $3$, serta kurung biasa (eksklusif) pada $-1$ dan $2$.
