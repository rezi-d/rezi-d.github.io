4. Menentukan Komponen Fungsi Pembentuk Komposisi

Jika pada materi sebelumnya kita merakit $(f \circ g)(x)$ dari komponen $f(x)$ dan $g(x)$, materi ini membahas proses kebalikannya (*reverse engineering*): bagaimana membongkar dan menemukan rumus fungsi pembentuk jika fungsi komposisi dan salah satu fungsi komponennya diketahui.

Poin 1 / 5
Poin 1 · Tipe 1: Diketahui (f \circ g) dan g(x)

🔍 Menentukan Fungsi Luar $f(x)$ dengan Pemisalan Variabel

Substitusi u = g(x)
💡

Ide Intuitif: Menyamarkan Kotak Dalam Menjadi Satu Huruf

Kita memiliki persamaan $f(g(x)) = \text{ekspresi}$. Karena kita menginginkan rumus $f(x)$ murni, bentuk rumit $g(x)$ di dalam kurung harus kita 'samarkan' menjadi sebuah variabel tunggal, katakanlah variabel $u$. Setelah itu, seluruh variabel $x$ pada ruas kanan harus kita ubah agar dinyatakan dalam bentuk variabel baru $u$ tersebut!

3 Langkah Baku Menentukan Fungsi Luar $f(x)$

1

Misalkan fungsi dalam sebagai variabel tunggal:

$$u = g(x)$$

2

Nyatakan variabel $x$ dalam bentuk $u$:

Lakukan manipulasi aljabar untuk mengisolasi $x$: $$x = g^{-1}(u)$$

3

Substitusikan ke persamaan $(f \circ g)(x)$:

Gantikan $g(x)$ dengan $u$ dan gantikan setiap $x$ di ruas kanan dengan fungsi dari $u$, lalu kembalikan simbol $u$ menjadi $x$ untuk memperoleh $f(x)$.

Contoh Terarah: Kasus Linier ke Kuadrat

Diketahui $(f \circ g)(x) = 4x^2 + 6x - 5$ dan fungsi dalam $g(x) = 2x + 1$. Tentukan rumus fungsi luar $f(x)$!

Langkah 1 & 2: Pemisalan dan Isolasi $x$

Misalkan $u = g(x) = 2x + 1$.

$$2x = u - 1 \implies x = \frac{u - 1}{2}$$

Langkah 3: Substitusi ke $(f \circ g)(x)$

$$f(u) = 4\left(\frac{u - 1}{2}\right)^2 + 6\left(\frac{u - 1}{2}\right) - 5$$

$$f(u) = 4\left(\frac{u^2 - 2u + 1}{4}\right) + 3(u - 1) - 5$$

$$f(u) = (u^2 - 2u + 1) + (3u - 3) - 5 = u^2 + u - 7$$

Ganti kembali variabel $u$ menjadi $x$: $$f(x) = x^2 + x - 7$$

Poin 2 · Tipe 2: Diketahui (f \circ g) dan f(x)

🎯 Menentukan Fungsi Dalam $g(x)$ dengan Pencocokan Aljabar Langsung

f(g(x)) = (f \circ g)(x)

Menentukan fungsi dalam $g(x)$ biasanya jauh lebih langsung dibandingkan Tipe 1 karena kita tidak perlu mencari fungsi invers sementara. Prosedurnya adalah memasukkan simbol $g(x)$ langsung ke dalam definisi rumus fungsi $f(x)$, lalu menyamakannya dengan fungsi komposisi yang sudah ada.

Formula Kunci:
$$f(g(x)) = (f \circ g)(x)$$
Contoh Analitis: Mencari Fungsi Dalam

Diketahui $f(x) = 3x - 5$ dan $(f \circ g)(x) = 6x^2 - 9x + 4$. Tentukan rumus fungsi $g(x)$!

Langkah 1: Masukkan $g(x)$ ke dalam fungsi luar $f$:

Karena $f(x) = 3x - 5$, maka:

$$f(g(x)) = 3g(x) - 5$$

Langkah 2: Samakan dengan $(f \circ g)(x)$ yang diketahui:

$$3g(x) - 5 = 6x^2 - 9x + 4$$

Langkah 3: Isolasi variabel $g(x)$ secara aljabar:

$$3g(x) = 6x^2 - 9x + 4 + 5$$

$$3g(x) = 6x^2 - 9x + 9$$

Bagi kedua ruas dengan $3$:

$$g(x) = 2x^2 - 3x + 3$$

Poin 3 · Trik Efisiensi Waktu Ujian

⚡ Trik Cepat: Evaluasi Nilai $f(a)$ Tanpa Mencari Rumus Umum $f(x)$

UTBK Shortcut

Dalam soal seleksi seperti SNBT, SIMAK UI, atau Ujian SAS, seringkali Anda hanya diminta mencari nilai angka tertentu, misalnya $f(5)$ atau $g(2)$, bukan rumus fungsi aljabar umumnya ($f(x)$ atau $g(x)$).

Prinsip Ekuivalensi Input:

Jika Anda mencari nilai $f(a)$ dari persamaan $f(g(x)) = H(x)$, Anda tidak perlu mencari $f(x)$ terlebih dahulu! Cukup samakan argumen di dalam kurung:

$$g(x) = a \implies \text{Cari nilai } x, \text{ lalu masukkan } x \text{ tersebut ke } H(x)$$
Simulasi Perbandingan Waktu:

Diketahui $(f \circ g)(x) = \frac{3x + 1}{x - 2}$ dan $g(x) = 2x - 3$. Tentukan nilai dari $f(5)$!

Cara Konvensional (Lambat):

1. Misalkan $u = 2x - 3 \Rightarrow x = \frac{u + 3}{2}$.

2. Susun rumus $f(u) = \frac{3\left(\frac{u+3}{2}\right) + 1}{\left(\frac{u+3}{2}\right) - 2} = \frac{3u + 11}{u - 1}$.

3. Ganti $u = 5$: $f(5) = \frac{3(5) + 11}{5 - 1} = \frac{26}{4} = \frac{13}{2}$.

Memakan waktu & rentan salah hitung pecahan aljabar.
Trik Cepat Nilai Input (3 Detik):

1. Kita ingin input di dalam $f$ bernilai $5$, padahal yang ada adalah $f(g(x))$.

2. Setel: $g(x) = 5 \implies 2x - 3 = 5 \implies 2x = 8 \implies \mathbf{x = 4}$.

3. Langsung masukkan $x = 4$ ke ruas kanan:

$$f(5) = \frac{3(4) + 1}{4 - 2} = \frac{13}{2} = 6{,}5$$

Selesai dalam 3 baris tanpa aljabar pecahan rumit!
Poin 4 · Penguatan Kasus Kompleks

📝 Contoh Soal Bertahap: Fungsi Rasional & Tiga Komposisi

Bedah Soal
Tingkat Menengah: Mencari Fungsi Luar Rasional

Diketahui fungsi $g(x) = \frac{x + 1}{x - 2}$ ($x \neq 2$) dan $(f \circ g)(x) = 2x + 5$. Tentukan rumus fungsi $f(x)$!

Langkah 1: Misalkan $u = g(x)$ dan cari $x$:

$$u = \frac{x + 1}{x - 2} \implies u(x - 2) = x + 1 \implies ux - 2u = x + 1$$

$$ux - x = 2u + 1 \implies x(u - 1) = 2u + 1 \implies x = \frac{2u + 1}{u - 1}$$

Langkah 2: Substitusi ke persamaan komposisi $(f \circ g)(x)$:

$$f(u) = 2x + 5 = 2\left(\frac{2u + 1}{u - 1}\right) + 5 = \frac{4u + 2}{u - 1} + \frac{5(u - 1)}{u - 1}$$

$$f(u) = \frac{4u + 2 + 5u - 5}{u - 1} = \frac{9u - 3}{u - 1}$$

Ganti kembali variabel $u$ dengan $x$: $$f(x) = \frac{9x - 3}{x - 1}, \quad x \neq 1$$

Tingkat HOTS: Menentukan Fungsi Tengah pada Tiga Komposisi

Diketahui $(f \circ g \circ h)(x) = 6x + 7$, $f(x) = 2x + 3$, dan $h(x) = x - 1$. Tentukan rumus fungsi tengah $g(x)$!

Langkah 1: Kupas fungsi paling luar $f$:

Kita tahu $f(\text{kotak}) = 2(\text{kotak}) + 3$. Maka:

$$f((g \circ h)(x)) = 2(g(h(x))) + 3$$

Samakan dengan nilai yang diketahui:

$$2(g(h(x))) + 3 = 6x + 7 \implies 2(g(h(x))) = 6x + 4 \implies g(h(x)) = 3x + 2$$

Langkah 2: Tentukan $g(x)$ dari $g(h(x))$ dengan $h(x) = x - 1$:

$$g(x - 1) = 3x + 2$$

Misalkan $u = x - 1 \Rightarrow x = u + 1$.

$$g(u) = 3(u + 1) + 2 = 3u + 3 + 2 = 3u + 5$$

Rumus fungsi tengah adalah: $$g(x) = 3x + 5$$
