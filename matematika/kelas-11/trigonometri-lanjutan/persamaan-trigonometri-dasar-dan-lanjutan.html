Persamaan Trigonometri Dasar & Bentuk Khusus $a\cos x + b\sin x = c$

Menemukan sudut-sudut yang memenuhi kesamaan trigonometri memerlukan pemahaman mendalam tentang sifat periodisitas gelombang dan kuadran sudut. Kuasai himpunan penyelesaian persamaan trigonometri dasar, persamaan bentuk kuadrat aljabar, transformasi kanonik $k\cos(x - \alpha) = c$, serta syarat eksistensi penyelesaian real.

Poin 1 / 5
Poin 1 · Fondasi Solusi Periodik

🔄 1. Persamaan Trigonometri Dasar (Derajat & Radian)

k ∈ ℤ

Karena fungsi trigonometri berulang tanpa henti setiap periode, satu persamaan trigonometri memiliki tak berhingga banyaknya solusi. Solusi umum dinyatakan dengan parameter bilangan bulat $k \in \{\dots, -2, -1, 0, 1, 2, \dots\}$:

1. Persamaan Sinus: $\sin x = \sin\alpha$

Memiliki 2 cabang sudut (Kuadran I & II):

① $x = \alpha + k \cdot 360^\circ$

② $x = (180^\circ - \alpha) + k \cdot 360^\circ$

Radian: $\alpha + 2k\pi$ atau $(\pi - \alpha) + 2k\pi$
2. Persamaan Cosinus: $\cos x = \cos\alpha$

Memiliki 2 cabang sudut (Kuadran I & IV):

① $x = \alpha + k \cdot 360^\circ$

② $x = -\alpha + k \cdot 360^\circ$

Radian: $\pm\alpha + 2k\pi$
3. Persamaan Tangen: $\tan x = \tan\alpha$

Hanya 1 cabang sudut (Periode $180^\circ$):

① $x = \alpha + k \cdot 180^\circ$

Radian: $\alpha + k\pi$
💡 Prosedur Penyelesaian Soal Interval:

1. Ubah ruas kanan ke fungsi trigonometri yang sama: misal $\sin 2x = \frac{1}{2} \iff \sin 2x = \sin 30^\circ$.
2. Tulis kedua rumus cabang solusi lengkap dengan parameter $+ k \cdot 360^\circ$.
3. Selesaikan untuk $x$ murni (bagi koefisien $x$ terlebih dahulu sebelum memasukkan nilai $k$).
4. Uji nilai $k = 0, 1, 2, -1, \dots$ dan catat nilai $x$ yang berada dalam interval permintaan.

Poin 2 · Aljabar Kuadratik

📐 2. Persamaan Trigonometri Bentuk Kuadrat

a u² + b u + c = 0

Bila persamaan memuat suku berpangkat dua, samakan terlebih dahulu seluruh jenis fungsinya (misal semua menjadi $\cos x$ menggunakan $\sin^2 x = 1 - \cos^2 x$), lalu gunakan pemisalan variabel aljabar:

Contoh Bedah Kasus: $2\cos^2 x - 3\cos x + 1 = 0$ untuk $0 \le x \le 2\pi$
Langkah 1: Substitusi Pemisalan
Misalkan $u = \cos x$. Persamaan bertransformasi menjadi: $$2u^2 - 3u + 1 = 0$$
Langkah 2: Faktorkan Persamaan Kuadrat
$$(2u - 1)(u - 1) = 0 \implies u = \frac{1}{2} \quad \text{atau} \quad u = 1$$
Langkah 3: Periksa Domain Validitas & Cari Solusi Sudut
Kedua nilai $u$ memenuhi syarat interval tertutup $-1 \le \cos x \le 1$.
  • Untuk $\cos x = 1 \implies x = 0, 2\pi$.
  • Untuk $\cos x = \frac{1}{2} \implies x = \frac{\pi}{3}$ (Kuadran I) dan $x = 2\pi - \frac{\pi}{3} = \frac{5\pi}{3}$ (Kuadran IV).

Himpunan Penyelesaian: $HP = \left\{0, \frac{\pi}{3}, \frac{5\pi}{3}, 2\pi\right\}$

⚠️ Waspada Akar Semu (Extraneous Roots): Jika faktorisasi menghasilkan nilai akar $u = 2$ atau $u = -1.5$, akar tersebut tidak memiliki solusi (kosong) karena rentang nilai $\sin x$ dan $\cos x$ terbatas mutlak pada $[-1, 1]$.
Poin 3 · Bentuk Kanonik

🎯 3. Persamaan Bentuk $a\cos x + b\sin x = c$

k cos(x - α) = c

Penjumlahan linear antara sinus dan cosinus dengan sudut yang sama selalu dapat diubah menjadi satu fungsi cosinus tunggal dengan pergeseran fasa:

$$a\cos x + b\sin x = k\cos(x - \alpha)$$
Nilai Pengali $k$
$$k = \sqrt{a^2 + b^2} \quad (k > 0)$$

Berasal dari teorema Pythagoras pada bidang koordinat Cartesius titik $(a, b)$.

Sudut Fasa $\alpha$
$$\tan\alpha = \frac{b}{a}$$

Kuadran $\alpha$ ditentukan secara eksklusif oleh tanda koordinat Cartesius $(a, b)$.

⚖️ Syarat Agar Persamaan Memiliki Penyelesaian:

Karena persamaan dapat ditulis sebagai $\cos(x - \alpha) = \frac{c}{k}$ dan nilai cosinus berada pada $[-1, 1]$, maka syarat mutlak eksistensi penyelesaian real adalah:

$$\left|\frac{c}{k}\right| \le 1 \iff |c| \le \sqrt{a^2 + b^2} \iff c^2 \le a^2 + b^2$$

Jika nilai $c^2 > a^2 + b^2$, maka persamaan tidak memiliki solusi real ($HP = \emptyset$).

Poin 4 · Faktorisasi Lanjutan

⚠️ 4. Persamaan dengan Sudut Berbeda & Jebakan Coret

Faktorisasi vs Coret

Bila persamaan trigonometri memuat sudut berbeda seperti $\sin 3x + \sin x = \cos x$, strategi terbaik adalah mengonversi jumlahan ke perkalian (Werner), lalu memindahkan seluruh suku ke satu ruas untuk difaktorkan:

Langkah Penyelesaian Terstruktur:

$$\sin 3x + \sin x = \cos x$$

$$2\sin\left(\frac{3x+x}{2}\right)\cos\left(\frac{3x-x}{2}\right) = \cos x$$

$$2\sin 2x \cos x = \cos x$$

Pindahkan ke ruas kiri: $$2\sin 2x \cos x - \cos x = 0$$

Faktorkan $\cos x$: $$\cos x (2\sin 2x - 1) = 0$$

Cabang 1: $\cos x = 0$   atau   Cabang 2: $\sin 2x = \frac{1}{2}$

🚫 JEBAKAN FATAL: JANGAN MENCORET FUNGSI DI KEDUA RUAS!

Jika pada baris $2\sin 2x \cos x = \cos x$ Anda mencoret $\cos x$, Anda mengasumsikan $\cos x \ne 0$. Akibatnya, seluruh akar penyelesaian dari cabang $\cos x = 0$ (yaitu $x = 90^\circ, 270^\circ, \dots$) akan hilang selamanya!

🔑 Selalu pindahkan ke ruas nol lalu faktorkan!
